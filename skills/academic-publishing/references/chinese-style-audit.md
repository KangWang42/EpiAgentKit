# 中文稿内容、结构与模板化表达检查

> 用于中文论文或学位论文终审。先确认必须保持不变的事实，再检查内容与结构，最后处理用词。搜索命中只提示可能存在的问题，不用于判断文本来源，也不要求机械清除所有命中。

## 目录

1. 检查顺序
2. 内容与结构
3. 用词和句法
4. 方法去工程化边界
5. 分部件检查
6. 搜索线索

## 1 检查顺序

1. 对照必须保持不变的事实，确认数字、统计方向、引文、公式、表图、研究对象、时间范围和结论方向均未改变。
2. 按 `section-content-playbook.md` 检查目的、方法、结果、讨论和结论是否逐项对应。
3. 按 `../academic-humanizer/references/patterns-and-preservation.md` 做可迁移性、结构完整性、段落功能、术语一致性及学术书面语检查。
4. 最后处理空话、抽象名词链、连接词、句法和标点。

不得以提高检测分数或表面“像人”为目标。禁止用固定句长、随机换词、故意口语化或制造语法瑕疵。

## 2 内容与结构

优先修复以下问题：

- **万能段落**：替换研究对象后仍可放进无关论文。用真实对象、范围、数据、方法或引文具体化；无来源时删除。
- **镜像结构**：每段都按“发现 → 与文献一致 → 可能原因 → 意义”展开。按证据关系合并或重排，不要求每个结果都配齐四步。
- **固定配额**：恰好四段引言、五节讨论、三条优势、三条局限、三条建议。数量应反映真实内容和期刊要求。
- **机械分条**：把连续论证强拆为（1）（2）（3）。只在内容真正并列且列表改善阅读时保留。
- **逐表复述**：把表中每个变量和数字写成正文。正文只选择与研究问题和解读有关的结果。
- **重复收口**：每段以“具有重要意义”“提供有力支撑”“有待进一步研究”结束。删除空转句或改为具体边界和影响。
- **章节错位**：结果写机制、讨论引入新结果、结论新增建议或引文、方法隐藏缺失或偏离。内容回到承担该功能的部件。

## 3 用词和句法

| 可能的问题 | 检查方法 |
|---|---|
| 近年来、广泛关注、至关重要、不可或缺 | 检查是否有具体事实；没有则删或具体化 |
| 充分证明、有力证实、显著优于、最佳 | 核对设计、比较对象、效应量和不确定性，必要时降级 |
| 已有研究、部分学者、专家认为 | 换成真实引文；无来源则标记待核 |
| 值得注意的是、我们可以看到、不难发现 | 直接陈述后文事实 |
| 此外、同时、另外连续出现 | 检查是否存在真实逻辑关系，必要时合并或重排 |
| 进行了……的研究、开展……的构建 | 改为具体动词，如“研究了”“构建了” |
| 实现……的提升、促进……的发展 | 写明谁改变了什么指标，或删除空泛评价 |
| 首次、创新性地、全面系统 | 要求可核实比较；无依据删除 |

标准术语、合法 hedging、必要被动语态和承担真实逻辑的连接词应保留。不要为避免重复而替换核心术语。

## 4 方法去工程化边界

删除无关的版本演进、尝试顺序、文件路径、内部变量、函数名、渲染参数和调试过程。保留同行复现和偏倚判断所需的：

- 样本来源与排除、缺失数据、质量控制和分析集；
- 变量或构念的定义、形成依据和关键参数；
- 非显然且影响解释的方法选择理由；
- 关键诊断、方案偏离、敏感性分析与验证状态；
- 软件或程序库信息中确实影响复现的部分。

“只写做了什么”不能被用来隐藏为何选择分析集、为何排除样本、如何处理缺失或为何报告某种估计。分析日记应删，方法学透明度必须保留。

## 5 分部件检查

- 摘要：服从期刊结构；数字足以支撑主要结论，不设最低个数；无正文外内容。
- 引言：背景和证据直达具体缺口；无万能开头、逐篇罗列或固定四段。
- 方法：可复现、透明、无教科书式常识解释和无关工程过程。
- 结果：顺序与目的和 estimand 一致；无强制分条、逐表复述、机制和宣传评价。
- 讨论：比较具体文献；解释有依据；无逐结果固定段式或固定局限数量。
- 结论：不引入新内容，强度与证据相称；不强制纯正面，也不机械加未来研究句。

## 6 搜索线索

可用全文搜索定位高风险表达：

```text
近年来|广泛关注|至关重要|不可或缺|具有深远意义|填补空白|突破性
充分证明|有力证实|显著改善|大幅提高|前景广阔|提供有力支撑
已有研究|部分学者|专家认为|值得注意的是|我们可以看到|不难发现
此外|同时|另外|与此同时|综上所述|凸显了|彰显了
首先.*其次|一方面.*另一方面|\（1\）.*\（2\）.*\（3\）
进行了.{0,8}(研究|分析|评估)|开展了.{0,8}(构建|探索)
```

逐条记录“删除、具体化、降级、合并、保留及理由”。只有无合法保留项时才期望零命中；引文标题、规范术语、准确统计表述和必要逻辑词不得机械删除。
