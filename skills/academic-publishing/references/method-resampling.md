# Bootstrap 与重抽样报告要求

只在稿件实际使用 Bootstrap 或其它重抽样方法估计不确定性、校正偏倚或进行内部验证时读取。不用于交叉验证、置换检验或数据拆分；这些方法按各自估计目标和经核验规范报告。

- 说明目标估计量、重抽样单位、是否保留配对、聚类或分层结构、重复次数、区间或校正方法、随机设置和失败重抽样的处理。
- 在结果中报告相应估计、区间或校正量，并说明它对应哪项正式分析；只写“采用 Bootstrap 验证稳健性”而没有对应结果不算完成。
- 重抽样不能自动修复错误的分析集、模型设定、混杂控制或稀疏数据；是否新增重抽样由研究问题、方案和实际审稿要求决定。
- 方法、结果、表图和讨论使用同一估计目标、重抽样结构和结果口径。
