# 预后模型与风险分层稿件要求

只在稿件实际构建、验证或比较预后模型、风险评分、列线图或分期系统时读取。不用于普通关联分析、病因研究或只报告单个风险因素的回归模型。

- 切点、分组、特征选择或合并规则在哪个数据集中确定必须如实说明；使用验证数据形成规则时不得称为独立或外部验证。
- 报告切点或分层规则的实际数值和确定方式，区分预设、数据驱动和数据驱动后取整，不在结果出现后改写为临床预设。
- 模型或分期比较报告估计值与不确定性，并按研究目的给出适用的区分度、校准度和临床效用；不以图形外观或单个点估计代替正式比较。
- 联合模型中的不显著结果结合共线性、估计精度和模型目的解释，不据此直接断言某系统没有独立预后价值。
- 说明协变量缺失、完整病例样本量和事件数，以及这些变化对模型拟合和验证的影响。
- 内部、时间、地域和外部验证按实际数据来源与隔离程度命名；实际使用重抽样时，再按 `SKILL.md` 的方法分流读取相应要求，不把重抽样设为所有预后模型的固定要求。
- 方法、结果、表图和讨论使用同一目标人群、预测时点、结局时间窗、模型版本和验证类型。
