# Word 拼装边界

实际 `.docx` 创建、编辑、渲染和验证由 `docx` skill 负责。本 reference 只保存论文内容层对 Word 拼装的要求，不指定 python-docx、pandoc 或其它固定实现。

1. 先确认目标期刊、学校或用户提供的模板；没有模板时使用 `docx` 的中性默认。
2. 数字按固定结果名称从 `results/results.yaml`、旧项目结果文件或用户明确指定的正式结果中取得，不根据章节 Markdown 反向认定结果。
3. 标题层级、题注、交叉引用、表格、公式、上下标和参考文献在实际 Word 中可用且一致。
4. 使用模板时保留既有样式、节、页眉页脚、域和编号；工具选择以不破坏这些结构为准。
5. 生成后渲染并检查分页、字体、缺字、表格跨页、图片裁切、题注和目录；文件能打开不等于版式通过。
6. 一次局部 Word 修改只验证授权范围；完整论文或学位论文才做全篇布局检查。

若某种转换工具无法保留当前模板要求，改用 `docx` skill 中已验证的其它实现；不得把对某个历史模板的限制写成所有 Word 文件的通用禁令。
