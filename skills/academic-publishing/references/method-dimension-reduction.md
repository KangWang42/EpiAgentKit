# MCA 与 PCA 报告要求

只在稿件实际使用多重对应分析（MCA）或主成分分析（PCA）形成维度、成分或得分时读取。不用于探索性或验证性因子分析、聚类、潜类别分析或其它名称相近但估计目标不同的方法；这些方法按其分析 skill、方法依据和报告规范另行确定字段。

- 说明进入分析的变量、类别或量纲、编码、缺失处理、分析单位，以及维度保留依据和实际采用的惯量或方差口径。
- 报告解释维度所需的类别坐标、载荷或贡献，并说明方向如何确定；轴的正负可整体翻转时，不把符号本身解释为固定属性。
- 维度名称由实际坐标、贡献和研究语境支持，并明确是当前样本中的经验性概括；没有测量模型证据时不写成已经验证的稳定潜变量。
- 后续模型使用维度或成分得分时，说明得分生成、方向处理、分析集和与原始变量的关系；正文、表图和模型系数使用同一方向。
- 方法、结果、表图和讨论相互对应；未进入正式结果的试算不写成已实施的正式分析。
