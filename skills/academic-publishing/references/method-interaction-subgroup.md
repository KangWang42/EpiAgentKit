# 交互作用与亚组分析报告要求

只在稿件实际实施交互作用、效应修饰或亚组分析时读取。单纯分层描述、按组展示基线特征或不同模型分别拟合，不自动等同于效应修饰分析。

- 说明预设或探索性层级、效应修饰变量、交互尺度、模型形式、检验家族和多重性策略；不机械规定所有研究采用同一种校正方法。
- 报告各亚组样本量或有效分母、层内效应估计与区间、交互作用估计或检验及其不确定性；必要时说明稀疏、无法估计或精度不足。
- 以交互证据判断组间差异，不比较“一个亚组显著、另一个不显著”。
- 探索性或低精度结果保持提示性，不据此提出已经证实有效的分层干预。
- 方法、结果、表图和讨论使用同一分析层级、效应尺度和多重性口径。
