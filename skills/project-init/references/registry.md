# 表图编号表

正式统计表和统计图需要固定名称与编号时，新项目在 `02_code/00_setup.R|py` 中维护表图编号表；旧项目可继续读取分立的 `config.R|py`。代码变量可以继续命名为 `TABLE_REGISTRY` 和 `FIG_REGISTRY`。这份表只说明每项表图的固定名称、当前顺序和编号，不记录项目目录、结果数字或运行历史。

## 使用原则

- 只有会在论文、报告、PPT 或咨询包中使用的正式表图才进入编号表；一次诊断、E0/E1 输出和内部中间结果不编号。
- 顺序由论文、报告或交付要求决定。新增、停用或调整顺序时，只修改编号表并重新生成受影响文件，不在多个脚本中分别手写编号。
- 主文和补充材料可分别维护；只有实际出现补充表图时才创建对应目录与清单。
- 文件扩展名、尺寸和分辨率按实际使用场景确定。表图编号表不强制所有图同时输出 PNG 和 PDF，也不限制期刊允许的其他格式。
- 表图实际使用了 `results/results.yaml` 中的哪些结果，就在相应结果的 `consumers` 字段中记录该表图路径；不得为没有使用的结果虚构关联。

示例：

```r
TABLE_REGISTRY <- c("baseline", "main_effect")
FIG_REGISTRY <- c("cohort_flow", "main_effect")
```

```python
TABLE_REGISTRY = ["baseline", "main_effect"]
FIG_REGISTRY = ["cohort_flow", "main_effect"]
```

正式投稿时，如期刊要求文件名不带编号、采用特定大小写或扩展名，可在准备投稿文件时转换；表图在项目内使用的固定名称不变。
