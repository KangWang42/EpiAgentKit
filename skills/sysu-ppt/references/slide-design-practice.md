# 学术幻灯片设计实践

本参考把演示设计原则转成 `sysu-ppt` 的选页、写作、配图与验收规则。它不提供可机械套用的装饰模板；官方模板负责品牌一致性，本文件负责信息结构、科研排版和必要的视觉证据。

## 1. 先写逐页设计说明

生成内容前先列故事板，每张实质内容页填写：

| 字段 | 要求 |
| --- | --- |
| 标题 | 一条结论式名词短语，不能只是“研究背景”“结果”“方法” |
| 主信息 | 听众离开本页时应记住的一件事 |
| 证据或结构 | 支撑主信息的真实数据、文献事实、比较、流程、机制、公式或实例 |
| 解释或边界 | 证据意味着什么，或在什么条件下成立；只保留一条 |
| 主视觉 | 统计图、证据图、结构图、表格、公式、代码、真实截图或无 |
| 版式 | 从内容关系映射到现有 API，不从“看起来不同”出发 |
| 口头内容 | 需要讲但不应写到页面上的定义、理由、细节和过渡 |

一页一条主信息。内容丰富指“主信息 + 最强证据或结构 + 必要解释或边界”完整对应，不是元素更多、文字更长或每页配图。

页数先服从用户要求和汇报时长，再根据内容关系与证据量自然决定。公开指南中的“一分钟一页”和仓库示例中的页数都只能用于初步估算，不能用来补页、删减必要证据或固定每页内容。

## 2. 内容关系到版式的映射

| 内容关系 | 首选构图 | API | 避免 |
| --- | --- | --- | --- |
| 单一结论 + 关键证据 | 结论式标题 + 大幅证据视觉 + 一条解释 | `sysu_add_image_caption()` / `sysu_add_image()` | 把图缩成角落，旁边堆完整段落 |
| 定义、方法解释、证据评述或边界 | 1–3 个完整段落；论点明确，句间关系连续 | `sysu_add_text()` / `sysu_add_two_text()` + `prose()` | 把连续论证拆成标签墙或项目符号墙 |
| 少量样本量、轮次数、组合数或模型指标 | 完整句子或简单对齐表；只有主要结果才适度强调并保留定义与不确定性 | `sysu_add_text()` / `sysu_add_table()` | 把上下文数字做成 KPI 看板或孤立的大号数字 |
| 公式 + 方法含义 | 可读公式 + 邻近的符号、条件和解释段落 | `sysu_add_text()` / `sysu_add_two_text()` | 大面积顶栏、多个海报分区或口号页脚 |
| 两组真正并列或对照 | 双栏或比较表，维度和顺序一致 | `sysu_add_two_text()` / `sysu_add_table()` | 左右栏比较维度不一致 |
| 3–4 个同层级对象 | 先用对齐表或短编号；仅在对象都很短且需要扫读时使用受控卡片 | `sysu_add_table()` / `sysu_add_cards()` | 把连续流程、下一步或长段正文切成 2×2 卡片墙 |
| 机制、流程、路径或层级 | 一张主图占正文区 55%–90%，必要时复用同一总体图并逐步突出当前内容 | `sysu_add_text_image()` / `sysu_add_image*()` | 用项目符号复述箭头关系 |
| 统计结果 | 发表级统计图 + 一条结果解释；数字从结果数字唯一来源读取 | `publication-figures` + `sysu_add_image*()` | 重画或美化出并不存在的趋势 |
| 方法比较、文献证据或计划 | 对齐的表格、矩阵或时间结构 | `sysu_add_table()` / `sysu_add_text_table()` | 彩色大表头、过密网格或逐格长句 |
| 代码与操作 | 关键代码 + 目的或输出说明 | `sysu_add_code()` | 完整脚本截图或不可读终端图片 |

## 3. 排版与视觉统一

- 版式由内容关系决定，不设固定页数内必须更换构图的配额。研究依据、方法解释、限制或讨论可以连续多页使用相同的自然段版式，只要各页承担清楚的语义单位并保持可读。
- 每页只设一个视觉焦点。大图、表格、公式、代码或核心结论只能有一个主角，次要内容降级为一条解释或题注。
- 统一标题、字体、主色、题注、图号和页码；变化来自信息关系、比例和视觉权重，不来自随机色块、图标、阴影、渐变或字体。
- 单页通常保持 80%–90% 的白色或近白中性区域，品牌绿用于标题、规则线、关键边框和少量强调；这是色彩面积约束，不是要求页面空置。红色等第二强调色通常低于页面面积的 5%。卡片不按项目随机换色，层级依靠字号、字重、位置和克制的明度差。
- 白空间用于分组和强调，不要求每个区域都有内容。若页面确有独立信息功能且排版平衡，可以保留留白；若内容不足以独立成页，就与相邻页合并或作为连续论证的一部分，不用关键数字、卡片或生成图填空。
- 需要连续解释复杂方法时，只有总体图能比段落更清楚地表达关系才复用该图；否则按语义拆成连续段落页。

### 干净、协调与内容主导

- 默认采用白色或近白背景、深色正文、一个主色和至多一个强调色；以字体层级、对齐基线、稳定边距和有意留白建立美感，不以装饰元素堆出“设计感”。
- 让主图、表格或主论点占据明确的视觉主导面积。页面若出现 2×2 等大面板、重复的“编号 + 标题 + 两行说明”框，先问这些框是否真的表示并列关系；没有比较或分类依据就改成段落、双栏、表格、时间结构或一张主图。
- 卡片只接受短对象：每项通常不超过一个短标题和 2–3 个显示行；任何完整论证、因果链、限制说明、下一步或结论都不直接放进卡片。四项卡片不应由默认 API 自动生成，需明确的短并列理由和布局选择。
- 除官方模板已有的固定品牌元素外，不添加装饰性左栏、眉题、徽章、KPI 面板、孤立大号关键词/数字、口号页脚或无信息的上下分区。连续自然段页可以保持同一网格；不要为了制造变化而左右换边、改卡片数量或新增解释图。

## 4. 文字与信息密度

- 标题使用结论式名词短语，尽量一行完成；避免“背景”“研究结果”“问题”等无信息标题，也避免反问和口语。
- 文字密度按页面功能分层：结论、比较和决策页可用 2–4 条精炼短句；定义、方法解释、证据评述和边界页允许 1–3 个完整段落。段落围绕明确论点展开，行长、行距和段间距以投影可读为准；一页过密时在语义边界拆页，不缩字，也不改造成海报模块。
- 段落的信息量由页面功能和已有材料决定。研究依据至少说明证据对象、发现及其与当前问题的关系；方法解释至少说明输入、处理、假设或输出中实际相关的部分；决策说明至少写清建议、依据、例外和影响中可由材料支持的内容。有材料却只剩标签和一句泛泛说明时，先补内容再排版。
- 不把所有页面都做成短标签。存在因果、条件、转折或限定关系时，用 `prose()` 保留完整句法；只有真正并列、可快速扫读的内容才用编号、项目符号或卡片。
- 页面只写讲述时必须看见的文字。逐字朗读的正文、图中已表达的关系和标题的重复解释全部删除。
- 既有模板标题默认 24 pt；正文 16 pt 仅为密集页下限，内容允许时优先 18–20 pt。主要结果可在句子、表格或图中适度强调；样本量、轮次数、组合数和普通关键词不孤立放大。最终以 1280 × 720 导出图和教室后排可读性验收。
- 正文与背景对比度至少 4.5:1；颜色编码必须同时提供形状、线型、标签或位置线索，不能只靠红绿区分。

## 5. 配图的准确性与审美

- 视觉只接受四种功能：呈现真实对象、组织关系、解释机制或提供证据，并且必须比自然段或简单表格更清楚。纯装饰图、剪贴画、无语义图标和伪造界面不进入实质内容页。
- 先核验对象、数字、标签、箭头、方向、时间和来源，再评价构图、配色与细节。高优先级事实错误未解决时，不得因“更好看”采用该图。
- 外部图必须来源可追溯、分辨率足够且许可允许使用；不得放大超过原始分辨率。真实界面和分析产物使用实际截图。
- 非统计视觉按 `research-visuals` → `imagegen` 生成并验收；统计图走 `publication-figures`；科研原始图像不做生成式重绘。
- 统计图在表达分布、趋势、效应、不确定性或组间比较时保留；若只是报告几个独立数值，改用句子或简单表格，不用彩色柱形或指标块制造比较感。
- 单页通常使用一张高质量主图，不拼贴多张风格不一的小图。多图确有比较意义时，统一裁切比例、视角、尺度、题注与对齐基线。
- 题注写对象和证据身份，解释写正文。图内只保留理解对象、关系、条件和关键状态所需的最小文字。

## 6. 交付前节奏检查

在幻灯片浏览视图和 1280 × 720 导出图中同时检查：

1. 只读标题能否还原完整论证顺序。
2. 每页能否用一句话说出主信息，并指向唯一的支撑证据或结构。
3. 是否出现连续卡片墙、2×2 等大文字框、装饰性左栏、眉题、KPI 面板、孤立大号数字或无信息分区；连续自然段页本身不是问题。
4. 正文或真实证据是否清楚可读，是否存在可删除而不损失含义的装饰。
5. 图、表、公式和数字是否与来源一致，题注和来源是否可追溯。
6. 是否有文字过小、连续长段、过量要点、低对比或只靠颜色传意。
7. 段落是否已经用现有材料完成解释功能，还是只有标签和单行空泛说明；后者先补足依据、过程、条件、影响或限制，无内容可补时合并页面。
8. 是否出现标题无意义换行、单字或单个标点独占末行、卡片正文只占一角、四宫格装入长句，或某栏明显重于另一栏；命中后优先精炼措辞、调整栏宽或改布局，不缩小字号。

## 7. 在线依据

以下页面于 2026-07-20 核验，仅吸收可迁移原则，不复制其模板或素材：

- [Harvard Catalyst: Slides](https://catalyst.harvard.edu/writing-communication-center/visualize-science/slides/)：assertion-evidence 结构、强标题、视觉证据、少用项目符号、高分辨率图片与一致外观。
- [Harvard T.H. Chan School of Public Health: Slide checklist](https://hsph.harvard.edu/research/health-communication/resources/slide-checklist/)：标题简明、项目克制、充足留白、对比度至少 4.5:1、非纯颜色编码；其中面向快速扫读的字数建议不覆盖本文件对解释页完整段落和连续段落页的内容驱动规则。
- [MIT NSE Communication Lab: Slide Design](https://mitcommlab.mit.edu/nse/commkit/slide-design/)：一页一个信息点、标题写明主旨、内容支撑主旨、提高信噪比、图表注释、统一格式和自然转场。
- [UC San Diego: Evidence-Based Presentation Design Recommendations](https://multimedia.ucsd.edu/best-practices/presentation-design.html)：图像优先但禁止装饰图，工作记忆“4 个组块”原则，显著性提示，高分辨率和无障碍替代文本。
