# 中山大学 PPT 工具接口、配图与视觉验收

本文件是 `sysu-ppt` 的工具调用、卡片约束、配图规范、逐页视觉自检和模板几何细则。编写 R 脚本前先核对 API 与卡片边界；确认需要配图时核对配图规范；生成 `.pptx` 后逐项执行 PNG 自检。

## API 速查

| 函数 | 版式 | 关键参数 |
|---|---|---|
| `sysu_init(tpl)` | 初始化、清空演示页 | `"default"`/`"模板1"`=中大医学；`"模板2"`=原公卫模板；或路径 |
| `sysu_add_cover(ppt,title,subtitle,author,date)` | 封面 | subtitle 用一行短副标题 |
| `sysu_add_text(ppt,title,blocks,top,height)` | 纯文字（全宽） | 独立且内容较短的页面可调 top/height 以保持文字位置和留白平衡 |
| `sysu_add_two_text(ppt,title,left,right,top,height)` | 双栏文字 | 两个 `block_list`；`top`/`height` 同时控制两栏 |
| `sysu_add_text_image(ppt,title,blocks,img,img_w,img_h,side,caption)` | 左右图文 | `side="right"`/`"left"` |
| `sysu_add_image_caption(ppt,title,img,img_w,img_h,blocks,img_pos,caption)` | 上下图文 | `img_pos="top"`/`"bottom"`；`caption="图N …"` |
| `sysu_add_image(ppt,title,img,img_w,img_h,caption)` | 整图居中 | |
| `sysu_add_table(ppt,title,ft,left,top,note)` | 表格 | `ft` 用 `sysu_flextable()` |
| `sysu_add_text_table(ppt,title,blocks,ft)` | 左文右表 | |
| `sysu_add_code(ppt,title,code_lines,intro)` | 代码/示例（显式浅底代码框） | 短代码框按最长行收紧并居中，长代码保留全宽 |
| `sysu_add_cards(ppt,title,cards,cols,intro)` | **受控例外**：2–4 个真正并列的短对象 | 默认不用于正文；长内容和未明确的 4 项会停止并提示改用段落/双栏/表格 |
| `sysu_add_section(ppt,title,subtitle)` | 正式汇报章节页 | **组会禁止调用** |
| `sysu_save(ppt,path,genre)` | 保存 + 体裁检查 + 顶端对齐修正 | 组会 `meeting`；正式汇报 `formal` |

- **文本助手**：`tx(text,size)` 正文 / `bd(text,size)` 加粗主色 / `cd()` 等宽 / `prose(...,line_spacing,space_after,space_before)` 成段 / `num_item(...,size,line_spacing,space_after)` 编号条目 / `bullet(...,size,line_spacing,space_after)` 圆点列表 / `sp(h)` 间距。解释页优先用 `prose()` 保留完整论证；字号与间距在可读范围内按文字量调整，不用来填满页面或掩盖内容缺口。
- **表格**：`sysu_flextable(df, widths, fsize, align)` — 绿表头 + 斑马行 + 三线表。

## 卡片约束（默认不用）

- 卡片不是科研 PPT 的默认版式。先用 `prose()`、`num_item()`、`sysu_add_two_text()` 或 `sysu_add_table()` 表达内容；只有用户明确要求卡片，或页面确实需要比较 3–4 个同层级短对象时才调用。
- `sysu_add_cards()` 只接受短对象：每项应是短名称、关键差异和适用边界；解释性长句、因果链、下一步、创新点、可行性和结论不得直接装进卡片。两项可作为双栏短并列例外；四项不再自动生成 2×2，未明确指定布局时会停止并提示改用段落、双栏、表格或拆页。
- 卡片页不应连续出现，也不应成为全篇主要构图。单页仍统一使用近白底、细边框和单一品牌强调色；禁止随机换色、高饱和彩色方块、厚重阴影、装饰图标和为填满页面而拉高卡片。
- 卡片正文超过约 2–3 个显示行，或两行卡片需要放入完整段落时，必须删减为短语、改用非卡片版式或拆页；不能依赖缩小字号或扩大空洞卡高。

## 配图规范（确认必要后使用 research-visuals）

- 配图先问“这张图是否比自然段或简单表格更清楚地提供证据或关系”。只接受真实对象、组织关系、解释机制或证据四类功能；若几段文字已能直接说明研究依据或方法，就保留段落页。纯装饰图、剪贴画、无语义图标、伪造界面和低清拼贴不得进入实质内容页。外部图必须核验来源、许可和分辨率，不得放大超过原始尺寸；真实界面与分析产物使用实际截图。
- 开题、答辩、中期和正式研究汇报生成前阅读 `../../research-visuals/references/research-figure-patterns.md`，逐页标记主要表达方式和是否确实需要图。背景页默认使用论点、自然段和引文，存在真实统计证据时可用统计图；方法页只为难以用段落或表格说明的时间、空间、变换、模型分支和验证关系配图；创新、可行性和研究计划优先结构化文字、真实前期结果和简单计划表。
- **只有逐页设计已经确认需要表达流程、结构、技术路线、包含关系、概念框架、机制或研究场景时，才调用 `research-visuals`**。封面沿用官方模板主视觉，不为显得丰富自动增加生成图；研究背景也不默认生成图片。确需图时，先读取实际模板、图片区、标题位置和配色，并按 `../../research-visuals/references/carrier-specs.md` 与 `../../research-visuals/references/scenario-playbook.md` 区分正文内容图和氛围图。Codex 有工具时直接使用内置 imagegen/image_gen，以高质量 PNG 嵌入 `sysu_add_image*`。只有 imagegen 实际不可用、用户明确要求 SVG/矢量源、编辑现有 SVG 或目标格式强制矢量时才使用 `svg-diagrams`；不得因生成结果不准确或不好看而切换。统计图仍走 `publication-figures`。
- 图位于侧栏时通常占 30%–45%；机制图占 45%–60%；分步方法采用文字 30%–35% 加图 55%–65%；总体技术路线占标题以下正文区 70%–90%，页内不再并列长段正文。多图必须等高对齐并逐图题注。
- 技术路线至少按项目实际覆盖“研究对象/数据源 → 采集与整合 → 纳排/清洗/QC → 变量或特征构建 → 研究问题及对应方法 → 验证/分层/敏感性 → 输出与解释”。研究问题与方法成对表达，不得只罗列模型名。复杂方法可复用同一总体图，并逐页突出当前讲解的部分。
- imagegen 图先按 `research-visuals` 在原始分辨率与实际幻灯片中双重核验。流程、框架和路线图逐字检查标签、数字、节点和箭头；有误时最多用 imagegen 定向修改两轮，不得用 Python、PPT 文本框或 SVG 覆盖层补字。第二次修改后保留当前图，披露内容硬伤、审美问题和实际页面影响，由用户决定是否继续。PPT 主视觉和章节配图默认不烧录标题或正文，由幻灯片原生文本承担。
- **图内不写标题、不写解释性句子**（最常被打回）：删掉 `labs(title=...)`、删掉像“偏离对角线 = 概率不准”“模型净获益最高的阈值区间”这类**讲道理的 `annotate("text")`**。图里只保留坐标轴、图例、必要的**数据标签**（如曲线旁的“病例/非病例”、参考线旁的阈值数值）。解释一律写到 PPT 正文或题注。
- **证据图、统计图、方法示意和技术路线必须有题注**：黑色、小字号（13pt）、居中、置于图**下方**。外部图同时在邻近位置或页脚写来源。用各 `sysu_add_image*` 的 `caption=` 参数；需要编号的图按出现顺序连续使用 `图1/图2…`。封面主视觉、纯背景图和章节氛围图不编号，也不强加题注。
- **图例要短**：不要把整句解释当图例标签（如“过度极端 slope<1（概率太极端）”）；缩成“slope<1 概率太极端”这类短词，解释移正文。图例条目过长且使用 `coord_equal` 时，图例与绘图区之间常出现大块空白，可使用 `coord_cartesian(expand=FALSE)` 并缩短标签。
- **图内字要够大（最常被打回的问题）**：统计图按接近嵌入尺寸渲染并放大字号；imagegen 流程/框架图按实际占位比例生成，节点标题与组标题在缩略图上仍须清晰，分支标题不得缩成注脚。发现字小一律回到 imagegen 完整图定向修正或重生成，不在 PPT 中补字或拉伸补救。
- **图不能有多余留白或空边**：`ggsave` 的画布长宽比要贴合内容，否则四周会出现不必要的空白。ROC、校准图等可用 `coord_cartesian(expand=FALSE)` 让绘图区充分利用画布；谨慎使用 `coord_equal`，因为它会把绘图区固定为正方形，常在另一方向留下大块空白。注释和图例应适当收紧，`plot.margin` 可按需减小。检查发现图的上下或左右有空条时，调整画布比例或坐标设置后重新生成。
- 中文统计图使用 `showtext`，从当前系统已有字体中按候选路径检测并注册；找不到兼容字体时报告缺口，不硬编码单一 Windows 路径，也不安装字体。
- 嵌入 `img_w/img_h` 只是**最大边界框**，`.fit()` 自动按 PNG 真实比例等比缩放，**不会变形**；给的比例不必精确。

## 自检（生成后必跑）

```powershell
$pp = New-Object -ComObject PowerPoint.Application
$pres = $pp.Presentations.Open("绝对路径.pptx", $true, $false, $false)
$pres.Export("png输出目录", "PNG", 1280, 720)
$pres.Close(); try { $pp.Quit() } catch {}
```

逐页读 PNG 检查（**每一项不合格都要改了重生成，不许将就**）：

- ⓪ **模板来源检查**：生成脚本已 `source(.../sysu_toolkit.R)` 并调用一次 `sysu_init(已选模板)`，输出封面与内容页可见所选模板的母版品牌元素；未从空白画布仿制模板。
- ⓪bis **内容与体裁检查**：按通用流程第 6 节核对首张实质页、主体完整度、凝练标题、正文重点与表格维度；组会无目录/汇报提纲/Agenda 页，无章节分隔/过渡页，具体思路页保留；生成脚本无 `sysu_add_section()`，并以 `genre = "meeting"` 保存。
- ① 字体对（宋体/Times）；
- ② **面积与位置合理**——正文、公式、图表和留白与信息量匹配，无无意义左栏、大面积顶栏或上下展报分区，也不溢出或截断；
- ②bis **段落内容完整**——已经从现有材料写清本页实际需要的对象、依据、做法、条件、影响或限制，不是几个标签配单行空泛说明；无材料时已合并薄页而非编造或装饰；
- ③ **逐页配图决策合理**——不需要图的页面保留自然段或简单表格，需要图的页面能明确回答对象、证据、机制、时间或路径问题；
- ④ **图内文字够大且逐字准确**——流程图/框架图框内字、坐标轴、注释在缩略图上仍清晰可读，偏小或错误在两轮上限内回到 imagegen 修正，达到上限后明确披露；
- ⑤ **图无多余空边**——图四周没有明显空白条，有则调 imagegen 构图、SVG 画布或统计图输出比例重渲染；
- ⑥ **非统计图关系正确**——节点、箭头、方向和层级与来源逐项一致，无伪文字、重复节点或无语义装饰；技术路线从数据源开始，完整呈现到验证与输出；
- ⑦ **来源与证据属性正确**——外部图可追溯，无水印、低清截图、缺图占位符和混杂画风；
- ⑧ **模板按内容适配**——母版品牌元素保留，但结构、密度、图文比例、留白和视觉权重已按本页信息关系优化，无机械套版、卡片墙或硬塞；
- ⑧bis **科研汇报而非展报**——页面没有额外的装饰性左栏、眉题、徽章、KPI 面板、孤立大号关键词/数字、口号页脚、四宫格、重复信息框、渐变、厚重阴影、无语义图标或装饰性横线；连续自然段页不因版式相同而判为问题；
- ⑨ **表格上下居中**——表格块在内容区垂直居中而非贴顶；
- ⑩ 图居中不变形；
- ⑪ 重点已加粗；
- ⑫ **页眉对齐正确**——默认模板的标题横线与左侧两块绿色矩形底边共线，公卫模板的标题横线与绿色竖条底边共线；
- ⑬ **图内无重复标题、无解释性长句**，内容图保留必要节点标签，讲道理的文字写到正文或题注；
- ⑭ **题注使用正确**——证据图、统计图、方法示意和技术路线有题注且编号连续，封面与纯背景图不强加编号；
- ⑮ **图例简短**；
- ⑯ **学术书面**（见主文件硬性规范 6）。

归档检查：当前目录仅保留一份稳定命名 PPT 与当前源；无“完善版 / 最终版 / v2 / final”等旧版；旧版批次可由 `09_backup/INDEX.md` 定位且含 `MANIFEST.md`。

> 图件大于 ~2000px 时图像读取工具可能报错，可先缩放到 ≤1280px 再读；或直接读 1280×720 的逐页导出 PNG。

## 已处理的模板几何问题

- **默认模板设计在 layout 而不在 master**：当前默认的中大医学模板封面、校徽和水印位于带设计的版式中，即 `cover="1_空白"`、`content="3_空白"`。误用普通的“标题和内容”或“空白”版式时，页面只会显示白色背景。
- **默认模板页眉**：`3_空白` 左侧自带两块绿色矩形；标题和 flextable 横线共同对齐到矩形底边，禁止复用公卫模板的纵向坐标。
- **公卫模板页眉**：`Title and Content` 自带单个绿色竖条；标题和独立 flextable 横线共同对齐到竖条底边。不得依赖标题段落边框，PowerPoint 对该边框的渲染不稳定。
- **几何参数唯一来源**：两套模板的页眉坐标只在 `scripts/sysu_toolkit.R` 的 `.TPL_REG[[...]]$header` 中维护；`G`、`.add_title()` 和调用脚本不得另写标题或横线坐标。修改模板后先重新测量版式中的对齐位置，再更新注册表并生成两套代表页验证，不能让两套模板共享同一纵向坐标。
- **正文偏下**：部分版式文本框默认垂直居中；`sysu_save()` 按字节把空 `<a:bodyPr/>` 设 `anchor="t"`，故**用 `sysu_save` 而非 `print`**。
- **表格垂直居中**：`sysu_add_table` / `sysu_add_text_table` 的 `top` 默认 `NULL` = 按表实际高度在内容区（1.58~7.0）自动垂直居中（行数少的表不再贴顶）。需固定位置时显式传 `top=` 数值。单元格内文字已由 `sysu_flextable` 设 `valign="center"`。
