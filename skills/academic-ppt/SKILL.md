# Academic PPT

本 skill 负责学术汇报的内容选择、论证顺序和逐页表达。实际 `.pptx` 操作始终加载 `pptx`；不复制文件格式工具的操作说明。

## 1. 先确认模板来源

新建或结构性重做前，先确认下列一种来源。用户已说明或现有项目已有权威模板时不重复询问；有多份同样可能的当前模板时再请用户指定。

| 模板来源 | 执行方式 |
| --- | --- |
| 用户提供的 `.pptx` / `.potx` 或权威参考稿 | 视为正式模板，保留母版、版式、主题、字体、品牌、固定页脚和比例 |
| 其它学校、机构、会议或汇报类型的指定模板 | 使用对方提供或项目确认的文件；没有文件时不伪造官方标识和品牌系统 |
| 无模板 | 用户明确选择后使用中性学术设计，不自动套用任何学校身份 |
| 明确中山大学 | 转 `sysu-ppt` 的官方模板流程 |

模板决定品牌和可用版式，不代替内容设计。模板卡位导致字小、关系隐藏、图表过窄或页面空洞时，在保留固定品牌元素的前提下重排内容，不机械填槽。

## 2. 确定体裁和材料边界

1. 确认汇报类型、听众、时长、使用场景、语言、必须覆盖的内容和已有材料。页数由时长、论证关系和证据量决定，不为凑固定页数补页。
2. 组会、文献分享、方法讲解或进展汇报必读 [meeting-and-journal-club.md](references/meeting-and-journal-club.md)。
3. 开题、中期、预答辩或正式答辩必读 [proposal-and-defense.md](references/proposal-and-defense.md)。
4. 只使用用户材料、项目结果数字唯一来源或可核验证据。不编造数据、结果、引文、伦理号、机构或作者信息；没有结果的开题稿只展示预设目标、方法、质量控制和计划。

## 3. 先写逐页故事板

实质内容页至少记录：页面功能、单一主信息、支撑证据或结构、必要解释或边界、主要呈现形式（正文、图、表、公式、代码或无）、版式和口头补充。

- 每页只让一个图、表、公式、代码、结论或关系成为视觉焦点。
- 内容页标题用能说明本页作用的名词短语，优先概括结论、关系或分析边界；不只写“背景”“方法”“结果”，也不使用口语反问。
- 页面只保留听众当下必须看见的文字。完整论证使用自然句法，不拆成卡片墙或口号；只有真正并列且需要快速扫读的内容才使用编号、项目符号或少量卡片。
- 封面可有一行必要副标题；实质内容页只保留一个标题区，不再叠加“架构总览”类附属说明标题。

### 内容优先的视觉合同

- 普通科研内容页默认采用“明确标题 + 1–3 个自然段或简单对齐文字/表格”。科研汇报不是展报或海报；美观来自字体层级、对齐、间距、行长和留白，完成度来自论证与证据，不来自页面上有多少个框。
- 纯文字页可以是正确选择：研究依据、定义、方法解释、证据评述、决策和边界优先使用自然段、编号短句或一张简单表。同一论证允许按语义拆成连续多页自然段，只要各页标题说明当前部分的作用、字号和行长可读，就不为打破连续文字而改成图形。
- 段落页必须把本页问题讲完整。回到已有材料，按页面功能补足研究对象、事实或依据、具体做法、适用条件、结果含义和限制中实际相关的部分；有材料却只写“标签 + 一句泛泛说明”属于内容未完成。材料不足以支撑独立页面时与相邻页合并，不编造事实、数字或引文填字。
- 除非权威模板本身固定包含，不新增可编辑的装饰性左栏、眉题、徽章、KPI 面板、孤立放大的关键词或数字、口号式结语和展报式上下分区。样本量、轮次数、组合数等少量上下文数字写入句子或简单表，不做成指标看板；只有单个数字本身就是需要强调的主要结果时，才可在同时给出定义和不确定性的前提下适度突出。
- 2×2 卡片、重复信息框、圆角面板和“标题 + 两行说明”阵列不是默认版式。只有用户明确需要卡片，或页面确实要并列比较 3–4 个短对象时才使用；每个对象只能有短名称、关键差异和适用边界，解释性长句改成段落、双栏、表格或拆页。
- 视觉系统保持干净协调：白色或近白底，深色正文，1 个主色和至多 1 个强调色；固定标题、正文、题注、页码和边距层级。不要用渐变、阴影、装饰性横线、无语义图标或多色框填补留白。
- 留白是信息层级的一部分。不要平均分配区域或为追求“每页都有模块”牺牲正文或真实证据；图、表或正文按内容关系取得合适面积。连续段落页可以保持同一稳定版式，不为制造构图变化添加无意义区域。

## 4. 按内容关系制作

- 研究依据、定义、方法解释、证据评述和限制默认使用 1–3 个完整段落；少量数值用句子或简单表格。统计分布、趋势或比较确实是本页证据时使用统计图；时间、流程、机制、层级或依赖关系无法由段落或表格同样清楚地说明时才使用关系图。
- 公式页使用可读但不过度放大的公式，邻近放置符号、条件和解释段落；不要把一个公式再拆成多个海报式分区、口号或装饰模块。解释图只有在能减少理解成本时才制作，不把两三段能够直接说明的依据或方法改成编号箭头链。
- 若候选布局出现多个等大文字框，先回到段落、双栏、表格或拆页；只有真实证据或关系需要时才改用主图，不要把“版面铺满”当作内容完整。
- 统计数据图调用 `publication-figures`；流程、机制、技术路线和图形摘要调用 `research-visuals`；真实界面、终端、论文页和分析产物使用实际渲染截图。
- 图表标题、坐标、图例、估计值、单位和题注与来源逐项核对。统计结果从项目结果数字唯一来源取数，不在幻灯片中手工改数。
- 保留模板字体和颜色系统；无模板时选择一组中性主色、一个强调色和一组可读字体，不使用随机渐变、多色卡片、剪贴画、无语义图标或标题下装饰线。

## 5. 生成并验收实际 PPTX

1. 用 `pptx` 检查模板，再按模板编辑或无模板创建流程写入内容。结构、文字、图表和题注同步完成，不先生成空框再留给用户填写。
2. 从 PPTX 提取全部文字，检查缺页、重复、错别字、顺序、占位文字、未核验数字和模板残留。
3. 按 `pptx` 的渲染分流导出逐页图像并实际检查。Windows 优先使用已安装的 Microsoft PowerPoint；LibreOffice 只在已存在时作为备选，不安装也不视为生成前提。
4. 逐页检查模板是否可见、内容是否完整、文字是否溢出、对象是否重叠、字号是否可读、图表是否变形、间距是否一致、题注与页码是否冲突。修正违反内容、模板或显示合同的问题后重新渲染。
5. 当没有任何可用的渲染器时，可完成 PPTX 包结构和文字检查，但必须标明视觉验收未完成，不把“文件可打开”说成“可直接上台”。

## 6. 完成条件

只在下列条件都成立时标为完成：

- 汇报体裁、听众、时长、模板来源和材料边界已确认；
- 逐页主信息与证据、结构或分析边界对应，没有空转页、填充页或伪造信息；
- 段落页已经用现有材料完成其解释功能，没有把可用的依据、方法、条件、影响或限制压缩成标签式短句；
- 实际 PPTX 保留权威模板并通过文字检查；有自动渲染条件时已通过逐页显示检查；
- 当前版使用稳定、含义明确的文件名，没有 `final`、`new`、`latest` 或多个无法判断的当前版。
