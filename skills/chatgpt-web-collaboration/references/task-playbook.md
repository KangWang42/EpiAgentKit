# ChatGPT 网页任务表

每批粘贴的文字先说明文档位置、必要上下文、锁定项和本批任务；长文按标题或段落编号分批，网页端只判断本批可见文字，不推断未提供的图像或格式信息。

| 子任务 | 发送内容 | 要求返回 | 本地验收 |
| --- | --- | --- | --- |
| 文献线索 | 研究问题、PICO/PECO、时间范围、已有关键词 | 中英文检索词、候选来源类型、可能遗漏方向；不确定的题名或标识符明确标记 | 用 `evidence-research` 逐条核验，未核验内容不得进入正式引文或证据矩阵 |
| 逐段审校 | 段落功能、读者、原文、锁定事实/数字/引文、允许范围 | 最多 3 个主要问题、完整修订稿、事实与含义核对、未知项 | 用 `academic-humanizer` 或原内容 skill 核对数字、统计方向、因果强度、引文归属和结论边界；完整论文只审查新增或实质修改部分 |
| 思路扩展 | 当前目标、已确认事实、已有方案、不可改变边界 | 分开列出可直接讨论、需新增数据/分析、需文献核验和应排除的方向 | 不直接改变 SAP、分析集、主方法、结果或正式结论；方法变化回到设计/分析 skill |
| 独立检查 | 原始任务、必要材料、验收标准；先不发送 Codex 的结论 | 可定位的遗漏、矛盾、反例、替代解释和严重程度 | 回到原始来源核对；分别记录采用、拒绝和待核验意见，一致意见也不替代原验收 |

提示只要求一项明确任务和紧凑结构，不让网页端补写未知事实、研究结果或引文。
