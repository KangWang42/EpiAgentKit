# PROTOCOL 与 SAP 字段规范

## PROTOCOL

- 研究背景与可核验依据
- 研究问题、目标和假设
- 设计、场景、数据来源、研究时间窗、时间零点与观测结构
- 目标人群、纳入排除、暴露或干预、比较策略
- 主要与次要结局、测量时点、判定来源
- estimand 与中间事件处理
- 偏倚、混杂、缺失和可行性控制
- 伦理、注册、数据权限与适用报告规范
- 版本、冻结状态和确认人

## SAP

- 分析人群与样本流
- 对象标识、每对象记录数、结局与暴露/预测变量的测量次数和时点、分析单位与聚类单位
- 变量编码、派生规则和有序水平
- 主要 estimand、效应量和置信区间
- 主要模型、协变量选择依据、相关结构或随机效应依据和模型诊断
- 缺失数据、异常值、多重性与信息泄漏控制
- 样本量、事件数或精度依据及全部假设
- 预设亚组、交互、敏感性和稳健性分析
- 随机过程、验证方案、软件环境与重复分析所需的脚本和说明
- 方案偏离记录和探索性分析边界

字段不适用时说明原因，不用空白或猜测值填充。研究设计审查以概念完整和定义可执行为准，不以模板字段数量为目标。

## 观察性研究的因果设计

研究目标是暴露或干预的因果效应时，先写出所要模拟的目标试验，再说明观察数据怎样逐项模拟它：

| 要素 | 目标试验中写什么 | 观察数据中怎样模拟 |
| --- | --- | --- |
| 资格标准 | 入组时可判定的条件 | 只用时间零点及以前的信息判定 |
| 处理策略 | 各组要比较的具体策略 | 用可观察记录定义，写明允许的偏离 |
| 分配 | 随机分配 | 在时间零点调整基线混杂 |
| 时间零点 | 满足资格、分配策略与开始随访的同一时刻 | 三者必须对齐 |
| 随访 | 起止与删失规则 | 同一规则用于各组 |
| 结局 | 定义、判定来源和时点 | 同左 |
| 因果对比 | 意向性或符合方案效应 | 符合方案效应需要处理时变混杂（如逆概率加权） |

- **时间零点对齐**：资格判定、处理分配和随访起点不在同一时刻时，会产生永恒时间偏倚（例如以“曾经用药”分组、从确诊开始随访）。按用药起始对齐时间零点，或把暴露作为时变变量处理。
- **新用户设计**：比较药物或干预时，默认纳入新开始使用者，并与积极对照或非使用者在同一时间零点比较；纳入长期使用者会引入存活者偏倚。
- **调整变量选择**：先画 DAG（有向无环图），调整足以阻断暴露与结局之间全部非因果路径的最小变量集。不调整中介变量和碰撞变量，不按单因素 P 值、逐步回归或“能收敛就放”选择混杂因素。DAG 与所选调整集写入 SAP。
- **未测混杂的敏感性分析**：报告 E 值，即未测混杂与暴露、与结局的关联各至少达到多大，才能把观察到的效应解释为零。R 中可用 `EValue::evalues.RR()`；结局常见时，HR 和 OR 分别用 `evalues.HR(..., rare = FALSE)` 与 `evalues.OR(..., rare = FALSE)` 近似转换。E 值不是检验，要结合领域中已知混杂因素的强度解释。

描述性、预测性和诊断性研究不需要因果调整集，也不应借用因果措辞；预测模型的变量选择按预测性能与临床可得性决定。
