## 使用边界

本蓝图是生成研究生学位论文开题报告时的内容规范，不是某一学校的固定模板。学校研究生院、院系当前模板和用户已确认要求优先；模板没有的模块不强行添加，模板要求的模块不得省略。每项内容都要能回答“研究者依据什么，在什么对象和条件下，计划做什么，以及如何判断是否完成”。

正式报告文件默认生成可编辑 `.docx`。Markdown 或纯文本只能作为方案锁定、内容草稿或预检输入；它们不能替代正式 Word 交付，也不能证明页面、表格、签字栏和目录可用。

维护 skill 时使用的结构完整性测试模板与正式报告严格分开。测试模板可在每节用一句话说明该节应完成的功能，随后用显式 `【结构测试填充：……】` 和连续 `x` 达到长文装配所需篇幅；需要外部来源的位置写 `【引文待核验：……】`，参考文献只列待核验需求，不虚构作者、题名、期刊或 DOI。测试模板必须运行 `--mode showcase` 通过，并在 `--mode archive` 下因占位内容失败；这些填充不能被当作实质性论证、真实引文或可归档正文。

## 文档组成

按官方模板的实际顺序组装；没有模板时按下列中性顺序，并明确标为待适配稿：

1. 封面和基本信息：论文题目、学位层次、专业/方向、作者、导师、培养单位、日期和模板要求的其他字段。
2. 摘要与关键词：仅在模板或院系要求时加入；用研究背景、目的、设计、对象、主要方法和预期产出压缩说明，不写结果数字。
3. 目录、图表目录或缩略语表：模板要求时由 Word 字段或稳定装配生成，不手工输入最终页码。
4. 开题正文：按本蓝图完成背景、问题、目的、内容、方法、技术路线、预期结果、创新性、可行性和计划。
5. 参考文献：只放真实、已核验且与正文对应的来源，格式服从官方要求。
6. 附件：变量字典、终点定义表、量表/问卷、研究流程、分析计划摘要、知情同意或数据安全材料等，仅保留实际需要的附件。
7. 表单和评议页：导师意见、专家意见、开题考核、签字和日期空位按官方模板保留，不代填评价或签名。

## 篇幅与深度预算

先服从学校、院系和用户已确认的字数、页数及表单要求。没有明确要求时，以中文正文约 19,000–28,000 字符、完整 DOCX 约 20–30 页 A4 作为中性完整稿的制作与分页校准范围；页数包括封面、目录、表格、技术路线、参考文献、附件和评议表单，不把该范围声称为任何学院的硬性规定。

正文不能只达到总字数。写作前在内容矩阵中为每一部分分配篇幅和最低内容组件，并按真实研究复杂度调整。矩阵用于逐部分生成：每一部分必须先登记组件和依据，再独立完成写作、语言终审、表图映射和验收；该部分关闭后才可进入下一部分，不能用总字数、标题数量或一次性拼装替代逐部分完成：

| 部分 | 中性篇幅预算 | 深度要求 |
| --- | ---: | --- |
| 立题背景、国内外现状与证据缺口 | 7,000–10,000 字符 | 连续完成问题负担、证据比较、方法差异、争议、缺口和研究必要性；关键事实逐条引用 |
| 研究意义 | 800–1,200 字符 | 区分理论、方法、实践或政策价值，并限定适用范围 |
| 研究目的、问题、假设和 estimand | 800–1,200 字符 | 主要、次要和探索性问题逐项对应人群、比较、结局和时间窗 |
| 研究内容 | 1,000–1,500 字符 | 说明任务、依赖、输入、输出和停止条件，不重复方法目录 |
| 研究方法合计 | 7,000–10,000 字符 | 研究设计与对象约 1,000–1,500；纳排与流程约 800–1,200；暴露/干预和比较约 1,000–1,500；终点与测量约 1,000–1,500；样本量约 600–1,000；数据管理与质量约 1,000–1,500；偏倚、缺失与敏感性约 1,000–1,500；统计分析约 1,500–2,200；伦理与风险约 800–1,200 |
| 技术路线与研究流程 | 500–800 字符，加可编辑图或表 | 解释关键节点、责任、输出和停止条件，不只放图 |
| 预期结果与成果 | 400–700 字符 | 写结果类型、表图和解释边界，不预写数值或结论 |
| 亮点与创新性 | 600–1,000 字符 | 以已核验文献为参照说明设计、数据、测量、方法或实施差异 |
| 可行性与风险应对 | 800–1,200 字符 | 分别核对数据、人员、技术、伦理、时间、经费和风险责任 |
| 工作计划 | 300–500 字符，加进度表 | 与伦理、数据获取、分析、写作和提交顺序一致 |

参考文献数量由实际论断和证据范围决定，不用固定条数凑篇幅。章节超出或低于预算时，在内容矩阵写明模板要求、研究复杂度或不适用理由。禁止用重复定义、空泛意义、同义改写、过长政策摘录或表格复述填充字数；每一段都要承担综述、比较、定义、论证、方法说明、风险控制或衔接功能。

## 正文完整蓝图

### 一、立题背景及依据

至少形成“问题与负担—已有证据—争议或不足—本研究必要性”的连续论证：

- 说明研究对象、疾病/暴露/干预或管理问题及其公共卫生、临床、理论或应用意义。
- 分别梳理国内外或不同研究场景的研究现状；说明证据类型、研究人群、主要结局和方法差异。
- 指出证据不一致、测量局限、选择偏倚、混杂、外推限制或实际应用缺口；不要仅写“研究较少”。
- 明确本研究要解决的科学问题或应用问题，并解释为什么现有数据、场景和设计能够回答它。
- 每个外部事实、负担数字、方法依据和指南要求都绑定可核验引文；缺失来源时标为待核验，不用常识补齐。

### 二、研究目的、问题和假设

- 默认使用单层“研究目的”，写出一个主要目的和必要的次要目的，使用“描述、估计、比较、评价、探讨”等可操作动词。只有官方模板或用户明确要求时才拆成“总体目标/具体目标”；不得因套用范本自动增加目标层级。
- 将目的转为 PICO/PECO 或适合本设计的研究问题，明确人群、暴露/干预、比较、主要结局、时间窗和 estimand。
- 给出可检验的主要研究问题和假设；若为描述性或探索性研究，明确不预设方向或因果效应。
- 区分主要、次要和探索性问题，后续内容、终点和统计分析必须逐项对应。
- 零假设表不是通用组成；只有模板、导师或已确认统计方案要求时才生成，并逐项核对其与 estimand、模型和检验的对应关系。

### 三、研究内容

按研究目的拆解任务，不重复方法段落：

- 研究对象进入和资料来源任务；
- 暴露/干预、比较、结局和协变量的构建任务；
- 数据质量控制和随访/实施任务；
- 主要、次要、分层、敏感性或质性分析任务；
- 预期形成的表格、图件、数据库、分析报告或论文部件；
- 各任务之间的先后关系、输入、输出和停止条件。

### 四、研究方法

#### 4.1 研究设计、场景和 estimand

说明研究设计名称、研究场景、时间零点、观察或干预周期、比较策略、主要分析集和目标 estimand。明确哪些结果属于关联、差异、预测、诊断准确性或实施评价，避免设计与论断不一致。

#### 4.2 研究对象和研究流程

写清目标人群、来源人群、招募或抽样方式、研究地点、研究期间、筛查流程、基线、随访/干预节点、退出和终止规则。给出研究对象流程图或可编辑流程表。

#### 4.3 纳入和排除标准

分别列出纳入标准、排除标准、退出/失访定义、分析集构成和特殊人群处理。每一条标准要能实际判断，避免“依从性好”“资料完整”等未定义表述。

#### 4.4 暴露、干预、比较和实施

说明暴露或干预的操作性定义、剂量/频率/持续时间、比较组、实施人员和工具、依从性或实施忠实度、交叉和方案偏离记录。观察性研究不得把暴露写成已实施的治疗效果；干预研究要说明两组共同接受的措施。

#### 4.5 结局、终点和测量

分别定义主要终点、次要终点、安全性结局、时间窗、测量工具、测量频率、判定阈值、单位、最小临床重要差异（如适用）和中间事件。明确结局优先级、评估人员、盲法或审核流程以及结果缺失的处理。

#### 4.6 协变量、混杂和偏倚控制

说明候选协变量的来源和时间顺序，区分混杂、中介、碰撞变量和暴露后变量。写出选择偏倚、信息偏倚、混杂、失访、回归均值、测量误差或实施偏差的识别与控制方案；必要时配备因果图或变量关系表。

#### 4.7 样本量或精度依据

给出设计所需的样本量/精度输入、效应尺度、主要结局、显著性水平、把握度、预计失访/无效资料比例、分层或聚类设计效应和计算来源。无法确认时保留待补信息并停止声称报告已完成；不得用常见数字替代。

#### 4.8 数据来源、测量工具和数据管理

说明数据库、病历、问卷、设备、样本或访谈资料的来源、授权、采集表、编码、变量字典、版本、去标识化、访问权限、备份、锁库和更正痕迹。量表、设备或诊断标准需说明版本、信效度或适用依据。

#### 4.9 质量控制

覆盖人员培训、标准操作、设备校准、重复测量、逻辑核查、缺失追踪、异常值复核、随访提醒、盲法/独立复核、数据锁定和方案偏离记录。写清发现问题后回到最早来源核对的动作，不能只写“严格质控”。

#### 4.10 统计分析计划

至少包括：

- 分析集、时间零点和排除流程；
- 描述性统计、分布检查和基线/流程表；
- 主要终点的主模型、效应量、95% 置信区间、假设和诊断；
- 次要终点、分层、交互和探索性分析的预设状态；
- 混杂调整或随机化分析的协变量口径；
- 缺失数据、失访、异常值和敏感性分析；
- 多重比较、早停、方案偏离或中期分析（如适用）；
- 结果呈现的表格/图件和解释边界；
- 软件、版本和可复现运行方式（仅填入已确认信息）。

#### 4.11 伦理、隐私和数据安全

说明伦理审查/备案状态、知情同意或豁免、风险与受益、受试者保护、撤回权、不良事件、隐私保护、数据跨境/共享限制和研究结束后的资料保存。伦理号和机构要求必须来自已核验来源。

#### 4.12 研究局限和风险应对

列出可能影响可行性、内部效度、外部效度、数据质量、招募、随访、实施和解释的风险，并为每项写监测指标、责任人、应对措施和触发停止/修订的条件。不要用“样本量有限、存在一定局限”替代具体说明。

### 五、技术路线或研究流程

用可编辑流程图、表格或分层文字展示“对象进入 → 资料/干预 → 质量控制 → 结局评估 → 数据锁定 → 分析 → 产出”。每个节点要有输入、动作、输出、责任和停止条件；正文解释图中最可能改变研究含义的决策。流程图不得是没有字段和关系的装饰图。

### 六、预期结果和预期成果

写可验证的结果类型和交付物：研究对象流程图、基线/实施表、变量与终点表、主要分析表、敏感性或安全性表、必要图件、数据字典、论文和答辩材料。不得提前填入效应量、P 值、样本量、方向或结论；明确结果解释受设计和数据质量限制。

### 七、研究亮点、特色及创新性

分别写设计、数据、测量、方法、实施或应用层面的可核查差异，并说明与已有研究相比的具体位置。创新性必须由已核验文献和本研究实际方案支持，不使用“首次、最佳、填补空白、国内领先”等无依据宣传。

### 八、可行性分析

分别说明数据/样本可得性、场景和人员进入、技术与统计能力、设备与经费、伦理和授权、时间窗口、合作条件。每项标记“已具备、待确认、需申请或存在风险”，不能以“条件成熟”概括。

### 九、工作计划

按月份或阶段列出文献核验、方案和伦理、工具准备、招募/数据获取、干预/随访、清洗和锁库、分析、论文撰写、预答辩和正式提交。计划日期必须与研究周期、伦理审批和数据获取顺序一致，并为延迟、失访或方案修订保留应对安排。

### 十、参考文献、附件和表单

- 正文引用与文献条目一一对应，文献身份、题名、期刊、年份、卷页、DOI/PMID（如适用）逐项核验。
- 附件只放实际需要的量表、变量字典、终点定义、技术路线、分析计划摘要、知情同意或数据安全材料。
- 官方表单、导师意见、专家意见、签字和日期栏必须保留空位，不替任何人填写意见、签名或日期。

## 研究设计分支

### 观察性队列、横断面或病例对照

必须说明时间零点/索引日期、暴露测量先后、对照或参照组、混杂控制、失访/选择机制、测量误差、敏感性分析和非因果解释。队列研究还要说明随访窗口和中间事件；病例对照研究要说明病例定义、对照来源和匹配/抽样；横断面研究要说明同时测量限制。

### 随机对照或其他干预研究

必须说明随机序列生成、分配隐藏、分组比例、盲法或开放标签理由、干预剂量/频次/持续时间、对照内容、实施忠实度、交叉和方案偏离、意向性分析、符合方案分析（如适用）、安全性监测和暂停/报告条件。

### 诊断、预测或模型研究

必须说明索引检测/预测变量、参考标准或结局定义、训练/验证/测试划分、时间顺序、缺失处理、性能指标、校准、内部/外部验证、过拟合控制和模型更新计划。不能把模型性能写成临床获益。

### 质性或混合方法研究

必须说明研究问题、理论或分析框架、参与者和抽样、资料收集、饱和/充分性判断、编码和复核、研究者反思、可信度策略、混合方法连接点和整合输出。不能用统计样本量或回归模型段落替代质性方法。

不适用的设计分支要在内部方法决策中写明理由；不得为了填满模板加入相互矛盾的模块。

## 表格、图件和附件

没有官方模板时，完整报告至少应考虑以下可核对的表格或图件，并按实际需要保留：

- 基本信息和模板字段表；
- 研究问题、estimand、主要/次要终点表；
- 纳入、排除、退出和分析集表；
- 变量、测量工具、单位、时间点和数据来源表；
- 样本量/精度输入与假设表；
- 偏倚、混杂、质量控制和风险应对表；
- 主要、次要、分层和敏感性分析计划表；
- 技术路线/研究流程表或可编辑图；
- 研究工作计划表；
- 需要时的安全性、实施忠实度、访谈提纲或附件清单。

表格要有编号、标题、完整表头、单位、脚注和正文引用；图件要有编号、图题、替代文字和与正文一致的术语。表格和图件不能只用于增加页数。

## 分块制作与最终装配

长报告先建立逐节 todo/内容矩阵，不依赖一次性生成。内容矩阵至少包含：章节/表图、研究功能、研究对象或数据输入、研究动作、主要变量或终点、与方法的衔接、预期输出、停止条件/依赖、唯一输入、证据来源、设计分支、篇幅预算、前置依赖、当前状态、阻断项和验收结果。每一行都是一个独立生成单元，必须按“登记依据 → 生成本部分 → 核对事实和语言 → 核对表图/交叉引用 → 标记已验收”的顺序关闭；未关闭的行不得进入最终装配。

按内容依赖推进，而不是按页数机械切分：

1. 锁定官方模板、题目、作者字段、研究设计和提交要求；
2. 完成背景、研究现状、证据缺口和研究意义，并逐条核验引文；
3. 完成研究目的、研究问题、假设、estimand 和研究内容映射；
4. 按设计分支完成对象、纳排、暴露/干预、结局、样本量、数据、质量、偏倚、统计和伦理；
5. 根据方法生成技术路线、变量/终点表、分析表、风险表和工作计划；
6. 完成预期结果、创新性、可行性、参考文献、附件和官方表单；
7. 装配 DOCX，并统一检查跨章节一致性、编号、交叉引用、目录和分页。

每一块必须在进入当前 DOCX 前通过其内容主流程：外部事实和文献先核验，设计和统计口径与 PROTOCOL/SAP 或用户确认内容一致，中文经终审，表图字段与正文一致。分块完成不等于整体完成；最后必须检查目的—内容—方法—技术路线—分析—预期产出的一一对应，关闭所有 todo 后才能判定完整。若任一行的最低内容组件、证据、语言或版式检查未完成，应保留为部分完成并停止装配。

## DOCX 装配要求

- 用户提供模板时复制或基于模板工作，不重设其样式；没有模板时显式设置 A4/方向/页边距、中文正文和英文字体、标题层级、表格宽度、页眉页脚和页码。
- 使用 Word 标题样式和可更新目录/页码字段；不要手敲最终页码或用图片替代可编辑表格。
- 技术路线、变量表、分析表和工作计划保持可编辑；图件提供替代文字，表格使用明确宽度并检查分页。
- 交付前依次做包验证、正文提取、内容完整度预检、结构检查、渲染/逐页检查和重新打开；渲染工具缺失时明确报告限制。

## 完整度停止条件

只有同时满足以下条件，才可称为“完整报告”：

1. 官方模板和研究设计已锁定，或明确标为待适配中性版；
2. 所有适用正文模块都有实质性论证，不是只有标题或一句空话；
3. 正文和各部分达到官方要求或本蓝图的中性深度预算，完整 DOCX 已按约 20–30 页目标完成实际分页校准；低于范围时有可核验的模板或研究设计理由；
4. 设计分支所需的研究对象、终点、样本量、偏倚/质量、统计和伦理模块齐全；
5. 表图、附件、表单和签字空位按实际需要完成；
6. 外部事实、方法、数字、引文和伦理信息均已核验，未核验项不会被包装成完成；
7. DOCX 能打开，目录/页码、表格、分页、字体和断行通过检查；
8. 没有个人信息泄露、生成过程痕迹、编造结果或不当因果表述。

正式报告还必须通过 `validate_proposal.py --mode archive`；结构测试模板只能通过 `--mode showcase`，且必须被归档模式阻断。

任一条件未满足，交付状态只能是“完整内容待模板适配”“待核验稿”或“部分草稿”，并列出缺口、责任人和下一步；不得以章节标题数量或文件能打开替代完整度判断。
