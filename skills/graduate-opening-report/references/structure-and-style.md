## 从样本提取的稳定共性

仅把用户提供的三份 PDF 当作匿名版式样本，不保留其中的题名、研究主题、姓名、学号、导师、单位、联系方式、签字、日期或元数据。可复用的观察是：

- 报告由封面/基本信息、开题正文、参考文献和表单或评议页组成，通常还有签字或日期空位。
- 正文使用中文学术书面语和数字/多级标题，标题层级一般可追溯到一级、二级小节。
- 核心功能稳定出现：立题背景及依据、研究目的、研究内容或研究方法、技术路线、预期结果、研究亮点/创新性、可行性、阶段计划和参考文献。
- 研究方法部分倾向于按数据来源、研究对象、暴露/干预、结局、协变量、分析方法和质量控制展开，而不是只写方法名称。
- 技术路线、变量/终点说明、工作计划和评议意见适合用表格或流程图承载；表格必须有字段、单位、脚注和可追溯正文。
- 参考文献和正文通常占据多数页数；正文段落以连续论证为主，避免只用短句或目录式口号替代解释。

## 结构映射

| 功能 | 常见标题变体 | 生成时的决定 |
| --- | --- | --- |
| 背景与依据 | 立题背景及依据；研究背景和立题依据；选题意义 | 以研究问题为主线整合背景、证据、缺口和必要性，不机械拆成国内/国外 |
| 目的 | 研究目的 | 写主要、次要目的和可检验问题；与 estimand、终点和时间窗对应 |
| 内容 | 研究内容；研究方案 | 按目的列任务、变量和产出；避免重复方法章节 |
| 方法 | 研究方法；研究设计与统计分析 | 写对象、数据、测量、偏倚控制、分析、缺失、伦理和质量控制 |
| 技术路线 | 技术路线；技术路线图；研究流程 | 图/表展示节点和依赖关系，正文解释关键决策 |
| 预期结果 | 预期结果；预期成果 | 只写可验证的结果类型和产出，不写未发生的数值 |
| 亮点与创新 | 研究亮点以及创新性；研究的亮点及创新性 | 只写与已有研究相比可核验的差异和贡献 |
| 可行性 | 可行性分析 | 分别说明数据、技术、团队、伦理、时间和风险应对 |
| 计划 | 各阶段的具体工作安排；研究工作计划 | 以阶段和日期为主，和研究周期、伦理及数据获取顺序一致 |
| 文献 | 参考文献；文献名录 | 只列真实核验来源，按官方格式统一 |
| 评议 | 导师意见；考核意见；开题报告情况 | 保留官方字段与签字空位，不代填评价或签名 |

## 版式选择

1. 先读取当前学校/院系模板；模板的纸张、页边距、字体、字号、标题编号、表格边框、页眉页脚和签字栏均视为可配置变量。
2. 没有模板时使用中性排版：白底黑字、正文与标题有清晰层级、段前段后和行距稳定、表格不使用装饰色块，保留足够签字空间。
3. 样本显示出不同页面尺寸、字体组合和表格/绘图密度。它们证明“可读的层级和表单功能”比复制具体数值更稳定，不支持任何单一学校的硬编码。
4. 若技术路线或研究框架需要图形，优先使用可编辑的表格、形状或矢量源；图内文字与正文术语、编号和缩写保持一致，避免生成不可核对的装饰图。

## 语言与论证

- 背景段落按“现象/问题—已有证据—不足—本研究必要性”递进，每个外部事实对应真实引文。
- 目的和内容使用可操作动词，如“描述、估计、比较、评估、探讨”，避免把计划写成已经证明。
- 方法使用确定的未来时或计划时态，写清谁、什么数据、何时、如何测量和如何分析；不堆砌软件名和内部实现。
- 创新性用“本研究将……与……结合/拓展/验证，可能为……提供依据”这类可核查表达，避免绝对化宣传。
- 可行性把已具备条件、待确认条件和风险应对分开，不能以“条件成熟”代替证据。
- 预期结果写结果类型、输出表图和解释边界；参考文献未核验时使用待补标记。
- 以研究者视角成文，不出现“根据模型提示”“本报告由 AI 生成”等生成过程说明。

## 不可迁移的样本差异

以下内容不得从样本直接升级为通用规则：具体页数、纸张尺寸、页边距、字体名称或字号、学校/院系名称、题名格式、表格线型、签字措辞、参考文献样式、研究主题、数字、结论、文献条目和个人信息。它们只能由官方模板、用户明确要求或可核验的当前规范确定。
