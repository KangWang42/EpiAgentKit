# PPT 新建与重建的中性设计参考

仅在没有既有模板的新建演示，或用户明确要求大幅重建设计时使用。已有演示的局部修改不加载本参考，也不据此改动其它页面。

## 建立视觉系统

- 由内容、受众、会场显示条件和机构模板决定配色、字体和视觉重点；没有模板时使用克制的中性方案。
- 一种颜色承担主要视觉重量，使用 1–2 种辅助色和至多一种强调色。正文和图标在实际显示条件下保持可读对比。
- 只选择一个有信息作用的重复元素，不以装饰数量衡量完成度。
- 使用环境已经具备且字符覆盖可靠的字体，优先保证可读性和跨设备稳定性。

## 页面结构

- 每页围绕一条主信息组织。可使用双栏、图文组合、比较列、时间线、流程或简洁文字页，结构由内容关系决定。
- 标题、正文、题注和来源形成清楚层级。正文段落左对齐，边距和对象间距稳定，不把页面填满。
- 图、表、流程、图标或形状只有在实质改善理解时才加入；纯文字能更清楚说明时保留文字页。
- 同一演示可随内容变化采用不同结构，但不为追求变化强行改变适合的页面。

### 内容优先的审美基线

- 让证据或主论点占据明确的视觉主导面积。默认是一张大图/表/主关系，或一块有足够行宽的正文；不是多个等大面板平均铺满。
- 2×2 卡片、圆角信息框、“编号 + 标题 + 两行说明”阵列只作为明确的短并列例外。长句、因果链、方法解释、下一步和结论必须使用段落、编号短句、双栏、表格、时间轴或主图；不能套进四个框。
- 干净协调优先于装饰：白色或近白背景、深色正文、一个主色和至多一个强调色；固定字体层级、边距、对齐基线和题注位置。不要使用渐变、厚重阴影、无语义图标、装饰性横线、随机换色或为了填空添加形状。
- 留白用于分组和强调，不用于掩盖内容不足。若页面显空，先补充有来源的证据或合并/拆分内容，再调整主视觉比例；不要把空白改成更多框。

## 避免的做法

- 不使用低对比文字或图标，不让题注、来源和页脚与正文碰撞。
- 不用标题下装饰横线、随机渐变、大面积无意义色块或装饰性图标制造“设计感”。
- 不因默认偏好套用蓝色，也不把某一页单独装饰后留下其余页面失去一致性。
- 不把左右互换或卡片数量变化视为内容结构已经改善；判断标准仍是信息关系和读者理解。
- 不把所有实质页做成同一种网格；连续页面应通过证据类型、比例和阅读路径形成节奏，而不是只替换框内文字。

完成后按 `SKILL.md` 的内容和视觉检查范围验收实际页面。
