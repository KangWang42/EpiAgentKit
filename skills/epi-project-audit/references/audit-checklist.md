# 正式发布审查清单

只有 R 正式发布使用全表；P 日常任务从中选择受影响项。

## 1. 数据与设计

- 原始数据根可识别且未被修改；来源、时间窗、版本和访问权限可追溯。
- 清洗数据的相对路径、格式、工作表或对象、用途和权威分析输入角色明确；存在多种表示时，镜像的记录键、字段、类型、缺失与非有限值语义已经核对。
- 目标人群、分析集、纳排顺序、暴露或干预、比较、终点和时间零点与 PROTOCOL/SAP 一致。
- 键、重复、缺失、异常范围、样本流失和最终分母有证据；异常处置没有静默改变口径。
- 正式统计估计使用的数据状态为 `analysis_ready`，阻断性未决项为零，权威输入哈希与状态记录一致；待核对异常、结构性未测和非有限值没有因导出为空白而混入普通缺失或插补。
- 研究设计、estimand、模型和效应量匹配；预设、偏离和探索性分析已区分。

## 2. 代码与执行

- 只有一个总运行脚本 `run_pipeline.R|py`，并从项目根目录启动独立进程运行。
- 总运行脚本按明确顺序调用各分析脚本；代码不依赖交互对象、某一用户电脑的绝对路径或未说明的外部状态。
- 数据准备脚本和正式分析脚本分开列出；第一项正式分析前执行分析就绪检查，分析脚本从状态记录取得权威输入，不另行读取未声明镜像。
- 对总运行脚本中的每个步骤，逐项记录其实际输入、写出的正式产物或统计估计，以及它在研究数据链中的职责。只读取既有产物并给出通过/失败结论、重新打开文件核对显示或执行发布验收的脚本属于独立检查，应由 `tests/`、`checks/` 或本次 workbench 单独运行，不进入 `02_code/` 或总分析入口；生成脚本内与该产物直接相关的科学不变量检查可以保留。
- 随机过程使用已经确认的随机种子或数据划分标识；确定性过程未加入没有作用的随机种子。
- 最近一次自动运行记录显示成功，并能找到相应命令、脚本、完整日志、环境说明和输出文件哈希值；该次运行后的输入、数据定义、分析脚本和正式结果哈希值没有变化。只改变检查、状态说明或下游格式不会使这次科学运行失效，也不构成再次完整重跑的理由。
- 完整日志中的 error、traceback、failed、warning、nan 已修复或解释。

## 3. 结果清单

- 新项目使用 `results/results.yaml`；旧项目 `07_paper/results.yaml` 只读兼容。
- 每个关键结果均填写 `producer`、`source`、`input` 或 `input_hash`、`analysis_set`、`run_id` 和 `consumers`；这些字段分别记录生成脚本、脚本内结果来源、输入、分析集、运行编号和实际使用该结果的文件。
- `run_id` 对应一次成功的自动运行记录；`producer` 所指脚本和输入文件存在，或具有可核验的外部身份。
- 数值与 `display` 由共用脚本生成，结果清单无直接手改痕迹；探索性峰值未混入主结果。
- `result_summaries.md` 如存在，与结果清单在同次运行中重新生成，并明确标注不可编辑。

## 4. 表图与正文

- 表图和正文的样本量、分母、估计、区间、P 值、单位、参照组和方向与相应结果一致。
- 每张正式表的内部字段 ID 唯一，显示标签与内部字段分开；以行键和字段 ID 将结构化来源与 DOCX、XLSX、Markdown 等实际展示逐字段核对。重复显示标签可以保留，但不得用重复字典键、命名列表或“关键数字出现”检查代替列映射。
- 稿件表图计划中的稳定内部 ID、主文/补充位置、展示编号、文件名、题注、正文引用和模板页签一致；正式目录没有注册表已删除或重编号后遗留的孤立旧产物。
- `consumers` 中列出的每个文件确实读取相应结果；没有使用的结果不要求出现在每一种成品中。
- 表图在最终显示尺寸可读；统计图的尺度、截断、图例、删失、风险集和不确定性没有误导。
- 校准斜率解释正确：小于 1 通常表示预测过于极端；大于 1 表示预测分布过窄、不够极端。

## 5. 解释与报告

- 观察性证据不写因果结论；探索性结果不升格为预设主要发现。
- 结论同时考虑效应量、不确定性、偏倚和适用人群，不以 P 值替代科学判断。
- 方法与结果不混写实现痕迹；局限具体且与数据和设计相符。
- 适用报告规范、真实引用、伦理、注册、资金、利益冲突，以及期刊、机构或法规要求披露的内容均已核对。
- 成品无助手口吻、生成过程、占位符、调试痕迹或主动工具归因；强制真实披露未被删除。
- 论文、研究报告、复现说明和内部核查的用途边界已分别核对；对外正文没有无读者功能的路径、导出、调试或版本演进，内部记录仍保留真实异常，会改变科学解释的问题没有被用途隔离所隐藏。
- 完整论文或论文级结构性重写的设计、estimand、方法、数据和报告规范模块已按实际研究激活并可定位；未激活模块没有生成空段落，也没有用单篇参考论文或一个项目的表图顺序冒充通用模板。

## 6. 交付、授权与隐私

- 当前正式稿或交付包采用含义明确且长期不变的文件名，并且只有一组现行文件；被替代版本可以恢复。
- 数据、模型和代码分享符合明确授权；直接标识符、凭证和内部探索材料未外泄。
- 咨询包的 `DELIVERY_CONTENTS.md` 与实际输入、总运行脚本、运行环境、输出文件和数据授权一致。
- 文件可打开，链接和引用有效；接收方的运行时和格式能力满足或限制已声明。
- 确定性检查 ERROR 为零；WARN 有处置或接受依据。
