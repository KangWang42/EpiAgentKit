# 论断强度校准

用这份规则判断结论有没有写得超过证据。论断强度由研究设计、估计精度、结果稳健性和证据质量共同决定，不由 P 值是否小于 0.05 单独决定。

## 1. 先按研究设计确定动词

| 研究设计 | 可以用的表述 | 不用的表述 |
| --- | --- | --- |
| 随机对照试验 | “降低了”“增加了”“干预组……较对照组……” | 推广到试验人群以外时不加限定 |
| 观察性研究（队列、病例对照、横断面） | “与……相关”“……者的风险较高”“……与较低的……相关” | “导致”“引起”“影响”“作用”“效应”“保护作用”“预防” |
| 采用目标试验模拟或其它因果识别方法的观察性研究 | 在写明识别假设的前提下可用“估计的效应” | 不写假设就直接使用因果动词 |
| 横断面研究 | “同时存在”“横断面上相关” | 任何暗示时间先后的表述 |
| 预测模型 | “预测”“区分”“校准” | 把预测因子写成病因或干预靶点 |

## 2. 可以写得较直接的情况

以下条件同时满足时，可以使用“结果支持……”“与……一致”等较直接的表述：

- 主要估计的区间较窄，排除了有临床意义的相反方向；
- 预设的敏感性分析不改变方向和大致大小；
- 主要偏倚已在设计或分析中处理，残余混杂的可能程度已经评估（如 E 值）；
- 合并多项研究时，异质性可以解释，预测区间与主要估计方向一致。

## 3. 必须收敛的情况

出现以下任一情况时降低措辞强度，并在讨论中说明原因：

- 只有单项研究，或证据来自探索性、事后或亚组分析；
- 区间宽，同时包含有意义的获益和危害；
- 敏感性分析改变方向，或结果依赖某个特定建模选择；
- 异质性高且无法解释，或预测区间跨过无效值；
- 证据质量评价（如 GRADE）为低或极低；
- 主要结论依赖叙述性综合而不是定量估计。

此时使用“提示可能存在……”“与……相关，但估计不精确”“结果方向与……一致，但需要更多研究证实”等表述。

## 4. 常见过强表述及改写

| 过强表述 | 改写 |
| --- | --- |
| “证实”“证明” | “支持”“提示” |
| “明确表明” | “显示” |
| “X 对 Y 有保护作用”（观察性研究） | “X 与较低的 Y 风险相关” |
| “差异无统计学意义，说明两者无关” | “未观察到明确关联，区间为……，不能排除……大小的关联” |
| “亚组中效应更强” | “在……亚组中估计值较大，但交互作用检验 P = ……，属于探索性发现” |
| “首次发现”“最佳” | 删除，或改为可核验的具体描述 |
| “独立研究结果一致” | “多项研究方向一致，但部分研究可能共享数据来源或人群” |

## 5. 审稿人最常质疑的地方

- 因果动词是否超出研究设计允许的范围；
- 把“差异不显著”写成“没有关联”或“两者等效”；
- 摘要和结论是否比结果部分写得更强；
- 观察性研究与随机试验或孟德尔随机化结果冲突时，是否只采信对结论有利的一方；
- 是否忽略了预测区间、残余混杂、多重比较或亚组分析的探索性质。
