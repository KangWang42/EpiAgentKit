# 流行病学研究报告蓝图

本参考用于完整研究报告、阶段结果分享、委托人汇报材料或可外发研究报告。它与论文共享事实和结果来源，但按读者的决策需要重新组织，不把论文删短后改名为报告。

## 目录

1. 写前读者约定
2. 内容组成
3. 正文与内部核查边界
4. 表图计划
5. 终审与完成

## 1. 写前读者约定

先锁定：读者与责任、报告用途、需要支持的决定、数据/结果截止日期、对外或内部边界、篇幅和模板、正文唯一来源、表图清单及目标文件。需要生成多类成品时，为论文、报告、复现说明和内部核查分别写允许信息、排除信息和输出位置；不从同一旧分析说明模板直接生成所有成品。

报告要让读者能够回答：研究做了什么、纳入了谁、主要发现是什么、证据有多确定、哪些风险会改变解释、下一步由谁在什么条件下决定什么。完整报告的内容矩阵记录每一部分的功能、问题、唯一来源、表图、输出、阻断项和验收证据。

正式结果报告的正文直接陈述研究对象、结局、实际采用的方法、观察结果、解释、局限和结论，不写分析人员的工作状态或版面取舍。诸如“正文主表聚焦”“当前数据能够支持”“模型均完成估计”“已经完成一致性核对”“最终效应形式”“待数据提供者确认”“如进入正式投稿流程”和“后续分析建议”等属于内部核查或项目管理语言；确有必要时放入内部工作记录，不能原样进入面向导师、合作者或投稿使用的结果正文。若某项数据、分析集或质量问题会改变科学解释，须在方法、结果或局限中如实说明其影响，而不是用状态句代替科学表述。

## 2. 内容组成

标题数量和内容深度由用途决定。研究报告沿用论文式学术表达，内容范围以当前问题为界。以下是按读者问题选择的候选内容模块，Word 使用连续正文和黑白学术版式：

1. **标题与版本**：标题直接置于连续正文首页，说明研究对象、核心问题和报告性质；注明日期或数据截止日期。阶段报告使用反映当前状态的稳定文件名。
2. **摘要（仅在用户明确要求时）**：按论文摘要的句法和证据边界，用短段落概括目的、设计与数据、实际分析人数、少量最重要发现和关键不确定性。摘要中的数字和解释均可在正文定位，并同时呈现效应信息与不确定性。
3. **研究问题与用途**：明确本报告支持的决定，不把已经运行的全部分析列为同等目标。
4. **数据与研究对象**：写清数据来源、时间、目标人群、纳排和各分析分母。样本选择、随访或分析集变化复杂且图示有帮助时再用流程图；不同分析分母在相应表图标明。
5. **变量与方法摘要**：只写理解结果所需的最终定义、参照、调整集、抽样设计、缺失处理、效应尺度和实际完成的敏感性分析。计分审计、字段名、包函数、脚本路径、版面取舍和失败试验进入内部核查；Methods 不评价结果，也不解释为何选择展示某张表。
6. **描述性结果**：报告样本构成、研究问题所需的关键分布，以及会影响解释或下一步的缺失和稀疏性。正文提炼读者需要的信息，不逐格复述表格；不同时间点或分析集分别写明分母。
7. **模型或专项结果**：按主要、次要、敏感性和探索性层级组织，不按脚本顺序。先写比较对象、指标或关联方向，再给效应量、95%CI、需要的 P 值、分析分母和模型调整层级；预先纳入研究问题的不同时间点或指标均按实际结果呈现，不因显著性不同而省略。结果段不写“不能作为临床工具”“需进一步验证”等讨论性评价。
8. **阴性、稀疏和无法估计项**：保留预设阴性结果；零事件、完全分离、区间极宽或不可估计时说明证据限制，不删行、不填 0、不解释为没有关联。
9. **解释与建议**：分开写数据直接显示、结合文献的解释和研究团队建议。建议说明依据、条件和责任主体，不能因为 P 值更小而选择方案。正式结果报告不把分析人员的待办、下一轮分析或投稿适配指令写成建议；只有报告用途明确要求行动建议时，才保留基于已报告证据的独立建议模块。
10. **局限与风险**：写会改变解释、推广或行动的选择、测量、缺失、稀疏、时间顺序、残余混杂和精度问题，并说明可能影响。程序调试、旧文件来源和工具缺失不冒充科学局限。
11. **结论**：与研究目的对应，保留主要关联方向和证据边界，区分已支持、未支持和仍不确定；不引入新数字、项目状态、分析计划或投稿计划，不使用“证明”“完全没有影响”或无依据的“最佳”。
12. **下一步**：仅在报告用途明确要求行动或决策时使用，写清依据、条件、对象和责任主体；不得把分析人员的待办事项、补跑模型或投稿流程指令混入正式结果正文。

生存、预测、诊断、纵向、中介、Meta 分析、复杂抽样或空间报告只采用与实际方法相符的报告要求；必须报告的内容、诊断和合法结论来自相应统计与设计 skill，不在本参考统一套成回归报告。

## 3. 正文与内部核查边界

对外正文不写队列追溯日志、旧新编码比较、调试、路径迁移、导出过程和失败试验。内部核查附件保留这些事项的现象、来源、影响、处置和待决定项，并明确用途。会实质改变分析集、偏倚、结果或结论的问题不能因“内部”标签而只藏在附件；应在责任人可见的正式位置同步其科学影响。

论文和报告可以共享数字、表图和事实，但报告必须重新判断读者任务、信息顺序、解释深度和行动。研究结果报告不写成软件日志，操作指南确需路径、命令或停止条件时按其功能保留。

## 4. 表图计划

每张表图先记录：稳定内部 ID、阅读问题、来源、正文/附录位置、展示编号、完整题注、正文引用、最终尺寸、内容检查、字段对账和文件检查。按报告阅读顺序编号，不按目录遍历或生成时间编号。

主报告只保留完成读者任务所需的表图。样本流程图回答谁进入分析，描述性表回答研究对象或目标总体是什么样，估计结果表或森林图回答方向与精度；其它图型只在相应方法确实采用且能回答问题时使用。详细协变量、模型诊断、缺失模式和替代口径按科学重要性进入正文、附录、补充材料或内部核查，不能只因结果不利而隐藏。正式统计表按研究问题组织行列；术前、术后或其它时间点使用清晰的父级行分组，避免把同一变量的原始值与分组值无目的地重复展示。表内不得出现内部检查字段、变量编码、程序状态或模型运行状态；`n/事件数`、效应量、95%CI、P 值、参考组和单位须能脱离正文理解，模型表注须写出各模型实际调整变量。

正文、表题和表注中的指代必须有明确范围。不要用“其余指标”“主要指标”“上述变量”或“两项结果”掩盖时间点和指标集合；若表格只含某一时间点的指标，正文也应明确写出该时间点，并列出会影响解释的具体指标。不同指标因缺失而产生不同分析分母时，表中真实显示各自 `N`，并在表注或正文说明缺失对解释的影响，不强行统一样本量。

统计表使用唯一内部字段 ID 和独立显示标签；DOCX、XLSX 或 Markdown 与结果来源按行键和字段 ID 对账。文件可打开、关键数字出现或版式整齐都不能替代字段映射检查。

## 5. 终审与完成

逐项核对：

- 用户明确要求摘要时，摘要、正文、表图和结论的分析人数、方向、估计和区间一致；
- 报告与论文共享同一结果来源，但结构、重点和行动符合各自读者；
- 重要阴性、稀疏和无法估计结果未被省略；
- 技术过程未泄漏到对外正文，必要科学风险和真实披露未被删除；
- Methods 中声称的每项正式分析均在 Results、表格或补充材料中有明确去向，且正文与表格的时间点、指标范围、分母、方向、效应量和区间一致；
- 结果段使用中性科研语言（如“未见明确关联”“未观察到统计学显著关联”“效应估计接近无效值”“由于可用记录较少，该结果需谨慎解释”），不把阴性结果写成“没有影响”“无意义”或“没有预测价值”；
- 每项建议有具体结果或真实外部要求作为依据；
- 内容功能、统计字段对账和目标文件结构/页面显示分别通过。

任一适用的研究设计或统计方法要求、关键数字来源或检查未关闭时，按实际状态称为部分报告或待核验稿，不因 Word 已生成、可打开或页面美观而称为完成版。
