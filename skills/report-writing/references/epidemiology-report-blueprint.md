# 流行病学研究报告蓝图

本参考用于完整研究报告、阶段结果分享、委托人汇报材料或可外发研究报告。它与论文共享事实和结果来源，但按读者的决策需要重新组织，不把论文删短后改名为报告。

## 目录

1. 写前读者约定
2. 内容组成
3. 正文与内部核查边界
4. 表图计划
5. 终审与完成

## 1. 写前读者约定

先锁定：读者与责任、报告用途、需要支持的决定、数据/结果截止日期、对外或内部边界、篇幅和模板、正文唯一来源、表图清单及目标文件。需要生成多类成品时，为论文、报告、复现说明和内部核查分别写允许信息、排除信息和输出位置；不从同一旧分析说明模板直接生成所有成品。

报告要让读者能够回答：研究做了什么、纳入了谁、主要发现是什么、证据有多确定、哪些风险会改变解释、下一步由谁在什么条件下决定什么。完整报告的内容矩阵记录每一部分的功能、问题、唯一来源、表图、输出、阻断项和验收证据。

## 2. 内容组成

按用途选择并调整深度，不固定标题数量：

1. **标题与版本**：标题说明研究对象、核心问题和报告性质；注明日期或数据截止日期。阶段报告不得冒充投稿定稿，文件名不用 `final-final` 等不稳定版本词。
2. **执行摘要**：用短段落概括目的、设计与数据、实际分析人数、少量最重要发现、关键不确定性和下一步。每个数字在正文可定位，不只写 P 值，不加入正文没有的解释。
3. **研究问题与用途**：明确本报告支持的决定，不把已经运行的全部分析列为同等目标。
4. **数据与研究对象**：写清数据来源、时间、目标人群、纳排和各分析分母。样本选择、随访或分析集变化复杂且图示有帮助时再用流程图；不同分析分母在相应表图标明。
5. **变量与方法摘要**：只写理解结果所需的最终定义、参照、调整集、抽样设计、缺失处理、效应尺度和敏感性。计分审计、字段名、包函数、脚本路径和失败试验进入内部核查。
6. **描述性结果**：报告样本构成、研究问题所需的关键分布，以及会影响解释或下一步的缺失和稀疏性。正文提炼读者需要的信息，不逐格复述表格。
7. **模型或专项结果**：按主要、次要、敏感性和探索性层级组织，不按脚本顺序。每节使用“回答问题的结论句—支持数字—不确定性—实际含义”，不以显著/不显著替代效应方向、区间和稳定性。
8. **阴性、稀疏和无法估计项**：保留预设阴性结果；零事件、完全分离、区间极宽或不可估计时说明证据限制，不删行、不填 0、不解释为没有关联。
9. **解释与建议**：分开写数据直接显示、结合文献的解释和研究团队建议。建议说明依据、条件和责任主体，不能因为 P 值更小而选择方案。
10. **局限与风险**：写会改变解释、推广或行动的选择、测量、缺失、稀疏、时间顺序、残余混杂和精度问题，并说明可能影响。程序调试、旧文件来源和工具缺失不冒充科学局限。
11. **结论**：与研究目的对应，区分已支持、未支持和仍不确定；不引入新数字，不使用“证明”“完全没有影响”或无依据的“最佳”。
12. **下一步**：只列真正需要责任人决定、补充材料、再分析或投稿适配的事项，写清决策主体和前置条件。当轮已解决问题不继续列为待办。

生存、预测、诊断、纵向、中介、Meta 分析、复杂抽样或空间报告只采用与实际方法相符的报告要求；必须报告的内容、诊断和合法结论来自相应统计与设计 skill，不在本参考统一套成回归报告。

## 3. 正文与内部核查边界

对外正文不写队列追溯日志、旧新编码比较、调试、路径迁移、导出过程和失败试验。内部核查附件保留这些事项的现象、来源、影响、处置和待决定项，并明确用途。会实质改变分析集、偏倚、结果或结论的问题不能因“内部”标签而只藏在附件；应在责任人可见的正式位置同步其科学影响。

论文和报告可以共享数字、表图和事实，但报告必须重新判断读者任务、信息顺序、解释深度和行动。研究结果报告不写成软件日志，操作指南确需路径、命令或停止条件时按其功能保留。

## 4. 表图计划

每张表图先记录：稳定内部 ID、阅读问题、来源、正文/附录位置、展示编号、完整题注、正文引用、最终尺寸、内容检查、字段对账和文件检查。按报告阅读顺序编号，不按目录遍历或生成时间编号。

主报告只保留完成读者任务所需的表图。样本流程图回答谁进入分析，描述性表回答研究对象或目标总体是什么样，估计结果表或森林图回答方向与精度；其它图型只在相应方法确实采用且能回答问题时使用。详细协变量、模型诊断、缺失模式和替代口径按科学重要性进入正文、附录、补充材料或内部核查，不能只因结果不利而隐藏。

统计表使用唯一内部字段 ID 和独立显示标签；DOCX、XLSX 或 Markdown 与结果来源按行键和字段 ID 对账。文件可打开、关键数字出现或版式整齐都不能替代字段映射检查。

## 5. 终审与完成

逐项核对：

- 执行摘要、正文、表图和结论的分析人数、方向、估计和区间一致；
- 报告与论文共享同一结果来源，但结构、重点和行动符合各自读者；
- 重要阴性、稀疏和无法估计结果未被省略；
- 技术过程未泄漏到对外正文，必要科学风险和真实披露未被删除；
- 每项建议有具体结果或真实外部要求作为依据；
- 内容功能、统计字段对账和目标文件结构/页面显示分别通过。

任一适用的研究设计或统计方法要求、关键数字来源或检查未关闭时，按实际状态称为部分报告或待核验稿，不因 Word 已生成、可打开或页面美观而称为完成版。
