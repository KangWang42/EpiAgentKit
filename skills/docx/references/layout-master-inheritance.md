# Word 版式母版继承与差异验收

当既有 Word 可能决定同一系列新文件或大幅重建文件的版式时，使用本参考。局部文字修订继续使用 `scoped-revision.md`；明确只供内容参考的 Word 使用 `content_source` 角色和内容 skill 的既定版式。

## 1. 锁定输入角色

逐个记录既有 Word 的路径、角色和判定依据，角色只使用：

- `content_source`：只提供事实、文字、表图或章节信息；
- `layout_master`：提供页面、层级、字体、颜色、表格及文档构成方式；
- `content_and_layout`：同时承担以上两种作用；
- `background_only`：只用于理解任务，不直接进入成品。

用户明确说明只取内容时使用 `content_source`；用户要求根据、参照或沿用同一研究的方案、报告或模板生成新报告时使用 `content_and_layout`。多个合理文件或角色会产生不同成品时先请用户选择。

## 2. 建立母版基线与确认变化

制作前检查并记录本次实际可能改变的母版属性：

- 文档构成：文首结构、连续正文、目录与固定内容容器；
- 页面：纸张、方向、页边距、分节、分页与栏；
- 字体与层级：正文和各级标题的字体、字号、字重、颜色、对齐、行距和段前后距；
- 页眉页脚：是否存在、内容类型、位置和页码逻辑；
- 表格与题注：边框、底纹、表头、对齐、表题/图题位置及字体；
- 其它稳定元素：机构标识、编号、主题色和固定说明。

把用户、机构或内容功能确实要求改变的项目单列为“确认变化”，写清理由。正文章节、表格行数和必要分页按内容需要调整；字体、颜色、文首结构和页眉页脚沿用母版基线或列入确认变化。

## 3. 选择制作路径

- 复制母版或在其包结构上生成，使样式、主题、页面和页眉页脚从同一来源继承；模板化生成器实际读取母版并复用其包结构。
- 已有母版时，以母版副本或能够读取母版的生成器作为制作起点。
- 报告章节和表图由内容 skill 决定；把新内容映射到母版已有层级。母版需要扩展层级时，从最接近的既有层级派生并列入确认变化。
- 能够保留母版基线并实现确认变化的制作方法方可进入正式交付；其它方法按实际状态交付为待适配稿。

## 4. 差异验收

交付前把母版基线、确认变化和成品逐项对照：

1. 运行包结构验证，并重新打开成品。
2. 核对页面、标题层级、字体、颜色、表格、文首结构、页眉页脚和内容容器逻辑；每个差异标为“母版基线”或“确认变化”。
3. 对严格颜色、题注、表图或文字要求，按 `delivery-requirements.md` 建立机器可读清单并运行审计。
4. 版式可能影响分页或页面显示时，渲染母版的代表页和成品全部受影响页面；核对字体替换、层级映射、表格续页、裁切、重叠和空白页。
5. 记录比较证据位置。成品版式等于母版基线加确认变化，且页面检查通过时，才能称为符合母版。

渲染检查证明页面显示，母版差异检查证明版式来源，两项证据共同构成母版交付验收。内容 skill 选择其它既定版式时，按该版式的任务清单验收。
