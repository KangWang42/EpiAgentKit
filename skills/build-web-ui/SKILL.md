# 构建网页与 Web UI

把网页视为内容、任务、品牌、工程和真实运行状态的统一产物。先建立页面与视觉合同，再实现和逐页验收；页面能显示、静态检查通过或首屏截图好看都不能单独证明完成。

## 按需读取与工具

- 确定风格、排版、内容密度、视觉角色或消除通用 AI 感时，读取 [design-playbook.md](references/design-playbook.md)。
- 个人生活、作品集、摄影、音乐、艺术、文化或活动站必须读取 [personal-cultural-sites.md](references/personal-cultural-sites.md)，按用户语气校准作者性与表达强度。
- 参考用户既有网页或在个人站、内容站与任务型工具之间选择设计语言时，读取 [local-reference-patterns.md](references/local-reference-patterns.md)。
- 用户要求寻找外部设计案例、开源仓库、悬浮、3D、视差、轮播或卡片切换，或实现可能引入新交互依赖时，读取 [external-design-research.md](references/external-design-research.md)。
- 开始性能、SEO、无障碍实现或交付前验证时，必须读取 [quality-gates.md](references/quality-gates.md)。
- 审计静态构建产物时，运行 `python scripts/audit_static_html.py <html-or-directory> [--root <site-root>]`。它只做确定性结构检查。
- 需要可复现的桌面与手机浏览器证据且本机已有 Chromium 浏览器时，运行 `python scripts/audit_browser.py <url...> --output <directory>`。它使用 Chrome DevTools Protocol（CDP）设置真实布局视口并输出 JSON 与截图，不自行安装浏览器。

## 1. 建立页面合同

1. 读取当前工作区规则、入口、路由、样式、组件、资源、构建命令和已有测试。保留来源不明的改动，不读取或回显 `.env`、凭证和私密配置。
2. 识别读者、核心任务、真实内容量、品牌语气、公开或登录状态、目标设备与必须保持的行为。只有会显著改变信息架构、技术栈或品牌方向的选择无法从材料推断时才询问。
3. 建立页面清单，至少区分公开页、登录/后台页和共享组件，并为每项写明主任务、真实长内容、空/错/加载状态、目标视口和验收路径。不得只改公开首页而默认后台已经一致。
4. 沿用既有框架、组件体系和依赖合同。新站选择满足需求的最小技术方案；不要仅为视觉翻新迁移框架、引入大型 UI 库或重写正常工作的业务逻辑。
5. 在编码前建立可检查的视觉合同：一句与内容有关的视觉命题，以及正文、标题、界面标签、数字、底色、正文色、主强调色、语义色、间距、几何、图像和动效的角色。每个角色说明用途与禁止滥用的位置；仅列色值或形容词不算完成。
6. 使用外部参考时，记录来源身份、可迁移模式、采用或拒绝理由、依赖选择和无动效回退。链接清单不能替代设计决策。

## 2. 组织内容与任务

1. 先排列用户要完成的任务和页面信息，再决定组件。每个公开首屏回答“这是什么、对谁有用、下一步做什么”，任务页先显示当前对象、状态和可执行动作。
2. 为公开内容提供稳定 URL、可抓取文本和清楚层级；为应用界面覆盖默认、悬停、聚焦、禁用、加载、空、成功、错误和权限不足状态。
3. 使用真实内容长度、真实字段和真实约束设计。不得编造评价、客户、统计数字、合作方、研究发现或功能状态来填满界面。
4. 让桌面、窄屏和触控布局各自成立，不把桌面版等比例缩小。优先重排、折叠次要信息、保持阅读宽度和操作目标，不隐藏核心功能。

## 3. 形成视觉系统并控制效果

1. 从内容和使用场景推导视觉，不套用固定“现代 SaaS”模板。至少建立一项与主题直接相关的识别特征，例如编辑式构图、内容索引、任务时间线、领域图形语言或真实材料质感。
2. 把颜色、字体、尺寸、圆角、边框、阴影、层级和动效写成少量 token，并映射到视觉合同中的角色。用截图和关键前景/背景对比度验证，而不是凭肉眼声称协调或合格。
3. 默认选择一个主表达手段和最多两个辅助手段。若同一视口同时出现 3D 倾斜、持续位移、滚动显影、自动轮播、视差、重复装饰运动中的两类或更多，先视为效果堆叠候选，逐项说明它服务的内容或任务；无法说明或关闭后层级更清楚时撤回。
4. 用户明确要求实验、沉浸或强动效时可以提高效果预算，但不得让核心内容依赖动画、hover 或高性能设备。导航、正文、表单、错误和权限信息保持稳定，触控、键盘和减少动效有等价路径。
5. 删除无内容依据的渐变、玻璃拟态、悬浮色块、同质卡片阵列、过量胶囊、假大空口号、随机图标盒与大面积空白；不得反向把所有页面收敛成低饱和、规则网格和无动效。
6. 需要原创品牌插画、英雄图或纹理且位图更合适时调用 imagegen。界面文字、数据、表单和真实产品截图留在 HTML/CSS 或实际浏览器渲染中，不烘焙进生成图片。

## 4. 实现真实网页

1. 使用语义 HTML、清楚标题层级、原生交互元素和可见标签。CSS 优先流式布局、容器查询或媒体查询与 token；JavaScript 只承担必要交互。
2. 保持业务逻辑、API、鉴权、路由和数据契约。视觉重构先识别行为测试，再小步修改；不要用静态假界面替换已工作的真实状态。
3. 为图像提供准确替代文本或明确空 `alt`、固有尺寸和适合容器的响应式资源。真实截图必须来自实际渲染；发现破图、溢出或字体回退时回到资源和布局源修复。
4. 动效只表达方向、因果和状态反馈。高级效果必须有静态基线、触控替代、键盘路径和 `prefers-reduced-motion` 分支；隐藏、离屏或失焦后停止连续更新。

## 5. 同步优化性能、SEO 与可访问性

1. 让公开核心内容尽早出现在 HTML 中，缩小关键渲染路径和客户端 JavaScript。优先静态或服务端输出，按路由和交互边界延迟非关键代码。
2. 让 LCP 资源可从 HTML 发现且不懒加载；为首屏关键资源设置合理优先级。首屏外图像和重内容再懒加载，使用 AVIF/WebP、`srcset`/`sizes`、尺寸声明和缓存。
3. 子集化并自托管必要字体，使用 WOFF2、可靠回退与合适的 `font-display`；只预加载确定会出现在首屏的关键字重。
4. 为可索引页面提供独立且准确的 title、description、canonical、一个主 H1、语言、可抓取链接、站点地图、开放图和与内容相符的结构化数据。登录、后台、预览和私密页面使用鉴权或 `noindex`，不要用 robots.txt 代替禁止索引。
5. 以 WCAG 2.2 AA 为最低目标：键盘可达、焦点可见且不被遮挡、标签与错误关联、对比足够、触控目标可用、缩放不受限、颜色不是唯一状态线索。

## 6. 实跑与浏览器验收

1. 运行项目已有格式化、类型检查、lint、测试和生产构建，扫描完整输出中的错误、警告、失败和资源异常。代码写完必须实跑。
2. 对适用的静态产物运行随附结构审计脚本。它通过后仍须完成真实浏览器、键盘和交互状态验收。
3. 用真实浏览器覆盖页面合同。至少检查约 1440 像素桌面和 CDP 仿真的 390 像素手机布局视口；记录 `innerWidth`、`clientWidth`、`scrollWidth` 与 `body.scrollWidth`。不得把 `--window-size=390` 的外窗宽度或被裁切的窄截图当作 390 像素移动端证据。
4. 每类页面至少检查首屏，以及一个锚点、滚动深处或任务状态。根据项目覆盖真实长文本、筛选表单、空/错/加载状态、弹窗、后台列表和编辑页；公开页与后台页分别验收。
5. 每个浏览器场景同时记录 H1 数量、重复 ID、缺失 alt、破图、横向溢出、控制台异常、脚本异常、HTTP 失败和网络加载失败。截图与机器结果使用同一 URL、状态和视口。
6. 计算关键正文、次要文字、按钮、链接、焦点和状态色与实际背景的 WCAG 对比度，记录前景色、背景色、比值与适用阈值。渐变、图片、透明叠层和 hover/focus 状态不能可靠自动判断时人工核对，不把未检查项写成合格。
7. 用键盘走完整核心任务，检查焦点顺序、表单错误、加载、空状态、失败恢复、对话框、返回路径与减少动效。移动端再检查触控等价操作和内容是否被祖先容器裁切。
8. 发现一类缺陷后扫描全部页面和同类组件；修复后重跑受影响测试、浏览器报告与截图。若高级效果破坏内容层级、核心任务、触控、键盘、减少动效、性能或低能力设备体验，撤回该效果。

## 完成判定

- 核心任务和既有行为可用，内容真实，公开与私密边界正确；公开页与后台页均有与其风险相称的证据。
- 视觉合同能说明主题来源和角色分工，关键颜色对比度已计算；页面不是通用模板换色，也没有未经解释的效果堆叠。
- 桌面与 CDP 手机布局视口下，首屏、深层内容和关键状态可读可操作，无未解释的溢出、裁切、破图、控制台或网络失败。
- 外部参考已转化为采用/拒绝决策；新依赖许可与版本清楚，高级效果具备静态、触控、键盘和减少动效回退。
- 构建、测试、静态结构、浏览器报告、截图、键盘路径和适用的性能或 SEO 检查有可复现结果；未执行项明确写为限制。
- 交付说明列出改动页面、视觉命题、验证命令、实际布局视口、已知限制和需要部署后观察的指标。
