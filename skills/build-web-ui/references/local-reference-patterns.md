# 参考站点的可迁移模式

这些站点只用于理解用户偏好和验证设计分流，不作为复制模板。读取时避开 `.env`、认证配置、用户输入、研究原始材料、输出 JSON 和其它私密数据；优先看视觉说明、入口页面、样式、公开资源和浏览器截图。

## 个人吃喝分享网页

- 用“吃喝手帐”而不是通用产品模板统领品牌图标、暖纸底、照片、编辑式标题和地图入口。
- 从站主语气校准安静、鲜明或实验强度；通过主场景、编辑式章节和材质语言形成作者性，不把个人站稀释成科研工具式卡片，也不把“有设计感”误做成效果堆叠。
- 首屏、指标、推荐内容和行动入口各有不同结构，但共享色彩、字体、间距和边框 token。
- 桌面是横向编辑版面，手机端重新排序文字、按钮和图片，不按比例压缩。
- 使用现代图片格式、字体子集、图片尺寸、开放图、动态 sitemap、真实 lastmod 和 SEO 审计，把审美与工程同时处理。
- 暗色模式、减少动效和内容可见性优化属于完整体验，不是交付后的补丁。

适合参考个人主页、生活档案、作品集、旅行、美食、摄影、音乐、文化记录、城市指南和其它需要作者气质的网站。

## R 语言教程站

- 让站点价值来自分类、搜索、侧栏、页内目录、代码与正文层级，不用装饰型英雄区掩盖大量内容。
- 限制阅读宽度，保持标题、段落、表格、代码、注释和边栏之间的稳定节奏。
- 用轻量强调色、边框和活动状态建立导航，不把每一段内容都卡片化。
- 静态生成页面直接提供 title、description、canonical、开放图和结构化数据；交互按需延迟，主题选择本地保存。
- 桌面三栏结构服务查找与阅读，窄屏再把导航与目录转为可访问的折叠交互。

适合参考教程、知识库、方法手册、技术文档、课程站和学术资源导航。

## 论文评分网页

- 借鉴清楚边界、任务编号和方法流程；原例的低饱和蓝灰只是科研审阅场景中的一个配色选择，不作为所有专业应用的默认主题。
- 把导入、文件、参数、运行、进度、报告与异常状态放在同一任务路径中，视觉层级直接服务操作顺序。
- 登录页使用与论文审阅相关的真实主题图像，主应用使用紧凑工作台；同一品牌允许页面密度不同。
- 使用语义表单、`aria-live`、原生 dialog、图片回退、固有尺寸和 `noindex` 登录页。
- 浏览器截图能暴露破图、字体回退、窄屏溢出和悬浮提示遮挡，必须把实际渲染作为验收证据。

视觉适用范围是科研审阅、研究数据录入和科研分析操作。普通管理台可借鉴状态、错误恢复和可访问性，但不能因此沿用科研保守配色与版式；其视觉方向按 `site-archetypes.md` 的页面用途分流。

## 组合规则

- 不从三个站点中选一个整套复制。可组合“教程站的信息架构、科研工具的状态语言、个人站的品牌气质”，但每个选择必须解释其服务的内容或任务。
- 优先复用抽象模式、验证方法和工程策略，不复制具体文案、图像、颜色值、布局尺寸或业务代码。
- 新需求与参考站点冲突时，以新需求的读者、内容和技术合同为准。
