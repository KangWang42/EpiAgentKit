# 图型与方法选择

本表用于根据研究问题选择图型，不提供来源不明或未经核查的示例代码。实现沿用项目现有绘图工具，并从真实数据或结果对象重新生成。

| 研究问题 | 常见图型 | 必查内容 |
| --- | --- | --- |
| 单个或多个效应及区间 | 森林图、点区间图 | 效应尺度、参照、区间、对数轴、权重与分组 |
| 连续变量分布 | ECDF、密度、箱线、小提琴、抖动点 | 样本量、重叠、异常值、带宽与原始点遮挡 |
| 类别构成或比例 | 点图、条形图、马赛克图 | 分母、排序、绝对数与比例、置信区间 |
| 两连续变量关系 | 散点、二维密度、平滑曲线 | 尺度、非线性、重叠、外推与混杂解释 |
| 时间到事件 | KM、累计发生、风险集表 | 时间零点、删失、竞争风险、风险集和区间 |
| 回归或边际效应 | 系数图、预测曲线、边际效应图 | 参照、调整集、交互、区间和适用范围 |
| 预测判别 | ROC、PR、时间依赖曲线 | 类别不平衡、验证集、时间点和不确定性 |
| 预测校准 | 校准曲线、校准截距与斜率 | slope < 1 过于极端；slope > 1 分布过窄；重采样与时间点 |
| 临床效用 | 决策曲线 | 阈值范围、净获益定义、基线策略和验证数据 |
| 高维矩阵 | 热图、聚类图 | 标准化、距离、聚类、色标和缺失 |
| 模型诊断 | 残差、影响点、假设检查 | 对应模型假设、异常点身份和是否改变推断 |

同一图不能同时承担所有信息。多个子图只有在共同回答一个问题且最终尺寸可读时才组合；否则分别放入正文、补充材料或诊断附件。
