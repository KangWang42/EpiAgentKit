# 原有绘图示例的核查要求

`references/recipes_common_50/`、`references/recipes_advanced/`、旧目录说明和索引当前不属于正式工作流。保留这些文件只是为了后续核对来源，并不表示已经获得使用授权、验证过统计方法或可以直接复用。

重新使用单个示例前必须完成：

1. 记录原始来源、作者、固定版本或提交、获取日期和完整许可证；无法确认再分发与修改权时不得纳入。
2. 移除安装命令、绝对路径、`setwd()`、私有数据、追踪链接、促销内容和与图型无关的代码。
3. 在项目隔离环境核对软件包身份、兼容版本、输入数据结构、随机性和必要依赖；不从非官方来源安装。
4. 由适用方法依据核对统计定义、变换、区间、检验、多重性、校准方向和默认参数。
5. 使用公开数据或合成示例数据实际运行，检查 warning/error/nan、数值、尺寸、字体、色觉可辨，以及放入实际论文、报告或演示页面后的显示。
6. 只把通过核查的最小通用实现重新写入正式 reference 或 script，并附来源与许可证；不恢复整套目录，也不让主流程强制调用原目录。

核查结论使用 `approved`、`rejected` 或 `needs evidence`，分别表示可以使用、不得使用或仍需补充材料。代码能够运行，并不表示统计方法适当或许可证允许使用。
