# 统计图工作流

本 skill 只处理统计量通过坐标位置、长度、面积、角度、颜色、大小或连续比例等视觉通道表达的统计图和诊断图。流程、病例筛选、机制、架构、技术路线与图形摘要转 `research-visuals`；节点含有真实样本量、排除人数、日期、阈值或比例也不改变这一分流。

## 1. 最低充分范围

- Q：解释图型、方向或规范，不创建文件。
- L：只修改一张指定的图或一个格式问题，保持原有布局和视觉表达，除非图中存在明确误导、不符合适用要求，或用户要求重新设计。
- P：从已验证数据或结果对象生成项目图，实跑代码并同步实际使用该图和相关结果的文件。
- R：在 P 基础上核验目标期刊当前官方 author instructions、投稿系统，以及图在论文、报告或演示文稿中的实际显示。

快速诊断或 E0 可只输出屏幕图或一个临时文件；不要求双格式、表图登记、归档或发布审查。速度优先通过缩小范围实现，不能省略数据与方向核对。

## 2. 作图前确认

开始前确认：

```text
问题：图要回答什么
来源：数据、结果对象或 `results/results.yaml` 中相应结果的固定名称
图中变量：横纵轴、分组、单位、参照和不确定性
用途：屏幕检查、论文、报告、PPT 或交付包
尺寸：最终物理尺寸或像素槽位
验收：必须看清和不得误导的内容
```

修改已有图时，先确认允许改变的数值、术语、标签、精度、注释或格式项；其余布局、图形元素和视觉表达保持不变。用户明确对样式不满，或原图不能回答研究问题时，再进行重新设计。

同时判断最近一次分析与检查是否仍适用于本轮修改。只改颜色、字号、留白、标签位置、图内说明或其它显示项，而且数据、结果对象、变量映射、分母、方向和不确定性均未改变时，沿用最近一次成功分析及结果哈希，只重建目标图，并更新实际使用该图的论文、报告、PPT 或交付文件；不得因此重新估计模型、重建无关表格或扫描无关日志。数据、分析集、模型、结果、坐标映射、分组、单位或科学解释改变时，从最早受影响步骤重跑。项目只有完整分析入口、不能安全地单独生成目标图时，先集中本轮已经确认的显示修改，全部明确后完整运行一次，并说明当前项目暂不支持单独生成该图。

用途是论文正文、补充材料或论文式成果示例时，读取 [论文统计图版式](references/manuscript-layout.md)。论文图与图注分工，不把 README 看板、报告摘要或 PPT 的信息层级带进图内。

图将进入完整稿、正式报告或补充材料时，从内容流程已经确认的表图计划读取稳定内部 ID、阅读问题、稿件位置、展示编号、文件名、题注和正文引用；不得按生成时间自行分配正式编号。需要显著性符号时，制图前锁定阈值、符号、是否显示不显著标记和多重比较口径。没有期刊、方案、用户或项目约定时，不自动把 `ns`、星号或 P 值设为通用默认。

## 3. 图型选择

按估计目标和数据结构选图，不照搬绘图示例或流行样式。常见选择见 [图型与方法](references/chart-gallery.md)。

- 比较效应及区间：森林图或点区间图。
- 时间到事件：KM、累积发生或相应模型预测图，明确风险集、删失和竞争风险口径。
- 预测性能：判别、校准和临床效用分别呈现，不用单一 ROC 代替完整验证。
- 分布与个体数据：点、密度、箱线或小提琴按样本量和重叠程度选择；柱形均值图通常不足。
- 关系与模型：散点及适当平滑、边际效应、残差或诊断图；不把趋势线当作因果证据。

## 4. 校准方向

校准斜率理想值为 1。方向解释必须与模型定义和绘图坐标一致：

- slope < 1：预测通常过于极端，常见于过拟合；高风险预测偏高、低风险预测偏低。
- slope > 1：预测分布过窄、不够极端；预测向总体平均风险集中。

校准截距反映整体风险偏差，曲线反映局部校准。不得把 slope > 1 解释为“预测过于极端”或“向中部压缩”。外部验证还需同时核对线性预测值定义、重校准模型和时间点。

## 5. 设计与输出

- 正确坐标、单位、参照、分母和不确定性优先于装饰。颜色不是唯一线索；最终尺寸下文字、点、线和图例可读。
- 默认一次只生成一张独立统计图。只有用户、研究方案、期刊或最终页面明确要求合图，而且各子图共同回答一个问题时才组合；不得为了展示能力主动拼合不同图型。风险集表、置信区间和该图必需的图例属于单图组成部分。
- 同一项目共享字体、具有固定含义的颜色和线宽，但不同图型按内容调整布局。明确需要多个子图时，只保留具有独立信息作用的子图，并逐对检查是否表达了重复内容。
- 论文图默认不在图内重复题名、副标题、样本描述、方法摘要、模型指标、P 值或限制说明；这些内容按作用进入正文或必要的图注，不自动堆到图题后。只有期刊、方案或读图确实需要时才保留一个必要的 P 值，并与结果唯一来源保持相同精度。图题通常只用简短名词短语标识图件。期刊或用户明确要求图内标题时，只保留一个居中短标题。风险集、分母或统计图本身要回答的评价指标仍按科学需要呈现；带计数的病例筛选流程仍由 `research-visuals` 处理。
- 图内使用领域通用缩写和短标签即可；不要写 `OR（对数……）`、模型教材式解释、实现备注或结论性句子。需要解释效应尺度、模型设定或结果含义时放入正文或图注。
- 子图标识的大小写、位置和字体服从目标期刊或项目规则，不设全局固定样式。
- 无目标期刊时生成中性工作稿：保留可运行代码和一个适合当前论文、报告或演示页面的高质量预览；需要编辑时保留矢量或可重建源。该工作稿不声称可直接投稿。
- R 正式投稿时以期刊当前官方说明决定 TIFF、EPS、PDF、PNG、分辨率、色彩空间、字体嵌入和尺寸。不能把 PDF + 300 DPI PNG 当作所有期刊的通则。
- 期刊未指定白色背景时，不把白色背景当作通用投稿要求；背景、透明度和边框服从版面与可读性。

不得检索近期论文只为模仿风格。需要当前规范时优先核验期刊、出版社或投稿系统的官方 author instructions；论文示例只能帮助理解内容惯例，不能替代官方技术要求。

## 6. 实现与验证

每项检查必须能指出本次修改可能造成的一种具体统计或图形错误；不能说明所防止错误的检查不执行，也不增加检查表、状态文件或缓存记录。局部显示修改默认只核对目标变化、图中其它内容未被误改，以及实际使用该图的成品已更新。

- R 使用项目现有 ggplot2 或既定绘图栈；Python 使用项目既有 matplotlib/seaborn 等。普通包缺失按依赖分流，用户不安装时优先验证现有 R 环境中的等价实现。
- 读取项目配色、有序分类水平、固定结果名称和表图编号表；不从私人材料或未经来源、许可和方法核查的绘图示例中复制安装命令、绝对路径、数据或方法。
- 代码写入主流程或 L 目标脚本并实际运行。验证完整日志、文件可打开性、像素或物理尺寸、字体、裁切、颜色、数值与结果清单。
- 连续修改同一张或同一组图时，每轮先用能够显示目标变化的最短运行路径生成预览并查看目标图，不重复完成全部交付检查。把已经确定的显示修改集中后，交付前只检查本轮可能受到影响的内容；新纠正只需增加与其相关的检查。
- 每项检查只需在当前上下文说明它用于发现什么问题、什么变化发生后需要重新检查，不建立项目记录文件。数据和结果来源、作图代码、被检查的图件内容均未改变时，沿用最近一次成功检查。重新生成一张图只需重新核对该图的文件、内容、可读性，以及实际使用该图的成品，不会自动要求复查其它表格、图件、模型、公式或日志。发现真实问题并修复后，只复查该问题及实际受其影响的后续文件。
- 需要修改数据、模型或结果时，回到实际生成结果的分析脚本，不在绘图代码中直接修正数字。
- 本轮已知修改全部明确后，在真实论文页、报告、PPT 或交付包中检查正式图一次；孤立图看起来清楚不代表嵌入后的字号、裁切和信息层级可读。用户要求立即交付、修改已完成或后续工作需要当前正式文件时，直接完成相应检查。

## 7. 原有绘图示例资料

仓库中原有的绘图示例代码和说明资料尚未完成来源、许可、依赖和统计方法核查，因此不属于当前正式工作流。本 skill、目录生成脚本、初始化器和正式示例均不得调用这些资料，不得自动安装其中依赖，也不得把它们作为方法或样式依据。重新使用其中任何一个示例前，必须按 [原有绘图示例的核查要求](references/recipe-quarantine.md) 核对来源、许可证、代码安全和统计方法；通过核查后，只把确有依据的最小通用实现重新写入正式 reference。

## 8. 完成条件

- 图回答已经确认的研究问题，来源、分母、单位、方向、区间和参照正确。
- 代码已经实际运行，异常已处理，图与 `results/results.yaml` 或已经确认的外部结果一致。
- L 的目标变化、实际使用该图的成品和范围外差异已经核对；仍然适用的成功检查没有重复执行。P 只同步实际使用该图或结果的文件。
- R 已核验当前官方投稿要求，并在实际论文页、报告或演示文稿中检查。
- 没有把中性工作稿、未经核查的绘图示例或探索性效果当作可直接投稿的成品。
