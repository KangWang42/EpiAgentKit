# 报告规范与方法学评价分流

报告规范用于判断信息是否完整、透明和可复核，不是研究质量评分工具。先按实际实施识别设计，再核对期刊要求和规范官网的当前版本；稿件自称的设计名称不能替代判断。

## 1. 常见文章类型

| 稿件类型 | 报告规范起点 | 额外分流 |
| --- | --- | --- |
| 随机试验结果 | CONSORT 2025 | 按集群、非劣效、实用性、伤害、非药物或 AI 干预选择扩展 |
| 随机试验方案 | SPIRIT 2025 | Registered Report 另服从期刊阶段标准 |
| 队列、病例对照、横断面 | STROBE | 营养、常规数据、分子流行病学等主题查对应扩展 |
| 诊断准确性 | STARD | 若含预测模型，同时核对预测模型规范 |
| 诊断或预后预测模型 | TRIPOD+AI | 开发、评价、更新和 AI 模型按实际目标选择项目 |
| 系统综述或 Meta 分析 | PRISMA 2020 | 方案用 PRISMA-P；范围综述、诊断、个体数据或网络 Meta 使用适用扩展 |
| 质性研究 | COREQ 或 SRQR | 按访谈、焦点组和其他质性设计选择，不机械叠加 |
| 病例报告 | CARE | 病例系列还需说明抽样、连续性和分析目的 |
| 动物实验 | ARRIVE 2.0 | 同时核对伦理、随机化、盲法、样本量和 3R |
| 卫生经济学评价 | CHEERS 2022 | 另检查模型结构、视角、时间范围、贴现和不确定性 |
| 医疗质量改进 | SQUIRE 2.0 | 区分本地改进与可推广因果论断 |

混合设计、二次分析、常规数据、机器学习或多阶段研究可能需要一个主规范加少量真正适用的扩展。不要为了“完整”堆叠互相重复的清单。

## 2. 使用方法

1. 从问题、抽样、分配、时间顺序和分析目标识别研究类型。
2. 先使用期刊提供的当前清单；未提供时从 EQUATOR Network 或规范官网寻找当前主规范和扩展。
3. 对每项记录 `present / partial / absent / not applicable / unclear` 及稿件位置。
4. `absent` 或 `unclear` 先形成 reporting gap，说明它阻碍了哪项判断；不要推断作者一定未执行该做法。
5. 完成报告清单后再评价设计、偏倚和统计。即使清单全部报告，也不能据此判定方法正确或偏倚低。

## 3. 方法学评价工具

只有在问题需要且专业范围允许时使用方法学工具，并到官方来源核验当前版本：

- 随机试验偏倚：Cochrane RoB 2；
- 非随机干预研究偏倚：ROBINS-I；
- 诊断准确性偏倚：QUADAS 当前版本；
- 预测模型偏倚与适用性：PROBAST 当前版本；
- 系统综述方法质量或偏倚：AMSTAR 2 或 ROBIS，按评价目的选择；
- 临床实践指南：AGREE II 等与目标相符的工具。

不要把领域工具总分机械转换成 accept/reject。逐域说明证据、判断和对主结论的影响。
