# 描述性统计与 Table 1

本文件规定描述性统计和 Table 1 的内容结构。Excel、Word 或其他文件中的具体写入与格式处理另用相应文件操作 skill；文件能打开不能替代本文件的统计内容检查。

## 1. 先确定统计口径

在计算前确认分析集、分组变量、每列分母、连续变量的汇总方式、分类变量的水平顺序、缺失值呈现和是否需要组间检验。这些选择由研究设计、SAP 和目标期刊决定，不由导出工具默认值决定。

- 连续变量按分布和研究用途报告均值（标准差）、中位数（四分位数间距）或其他已确认统计量。
- 分类变量报告 `n（%）`，写清列百分比、行百分比或总体百分比；未知或缺失是否单列必须与分析和正文一致。
- 只有设计、SAP 或目标期刊要求时才添加 P 值或标准化差异；不得把 `add_p()` 当作 Table 1 的默认步骤。
- 组名或列注中给出必要的总样本量，正文、表头、表注和模型分析集的分母应能相互核对。

## 2. 分类变量的行层级

默认只设置一个说明列（stub column），在同一列中放置变量名称和分类水平，后面才是各组或总体统计列。除非用户提供的正式模板明确要求，不增加独立“分层”“水平”列。

```text
特征                         暴露组（N=...）   对照组（N=...）
分析集总数                   n                 n
性别
  女性                       n（%）             n（%）
  男性                       n（%）             n（%）
  未知或其他                 n（%）             n（%）
年龄组
  <18 岁                     n（%）             n（%）
  18–64 岁                   n（%）             n（%）
  ≥65 岁                     n（%）             n（%）
  未知                       n（%）             n（%）
```

- 每个分类变量名称只出现一次，作为变量标题行；分类水平放在其下方并在同一说明列显示。
- 变量标题行与分类水平行在数据中保留明确的行类型或缩进级别，不能先丢失层级后靠人工空格修饰。
- 连续变量通常一行完成，名称和汇总统计放在同一行；需要多个统计量时按已确认模板处理。
- 二分类变量在全表统一选择一种方式：直接报告含义明确的“是”或“有”一行，或保留变量标题行并缩进列出适用水平。不得出现读者无法判断分母或参照含义的双列结构。
- 变量标签、水平名称、顺序和合并方式来自方案、代码中的口径常量或已确认模板，不由字母顺序或文件写入顺序决定。

## 3. 实现

可以使用 `gtsummary` 生成常规表，也可以构建包含 `row_type`、`indent_level` 和显示标签的中间数据。辅助字段用于检查与格式处理，不作为最终可见列。

```r
library(gtsummary)

table_1 <- data |>
  select(age, sex, bmi, group) |>
  tbl_summary(
    by = group,
    statistic = list(
      all_continuous() ~ "{mean} ({sd})",
      all_categorical() ~ "{n} ({p}%)"
    ),
    label = list(age ~ "年龄", sex ~ "性别"),
    missing = "ifany"
  ) |>
  add_overall()
```

组间检验确实适用时，再根据变量类型、分布、样本量和设计选择 t 检验、Wilcoxon 秩和检验、方差分析、Kruskal–Wallis 检验、卡方检验、Fisher 精确检验或考虑配对、聚类和抽样设计的相应方法。

## 4. 文件生成与检查

- 在 `config.R` 的表格登记中注册正式表名，并由主流程生成当前版本。
- 写入 Excel 时使用单元格的真实缩进属性表示分类水平，不用前导空格、全角空格或字符串拼接模拟缩进。
- 文件生成后同时核对内容和显示：变量名称是否只出现一次、分类水平是否归属正确、顺序是否正确、总数和百分比能否与来源数据及分母核对、辅助字段是否隐藏、缩进是否真实存在、表注是否说明统计口径。
- 只检查工作簿能否重新打开、列宽、冻结窗格或颜色，不能证明 Table 1 内容合格。

任一变量名称在分类水平行重复、分类水平脱离对应变量标题行、二分类含义不清、分母不一致或缩进仅靠空格实现时，不得把统计表工作项标为完成。
