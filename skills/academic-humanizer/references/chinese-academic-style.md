## 1 职责与基调

把本文件作为中文论文、学位论文、开题报告、研究报告和专业技术报告的共用语言门控。内容 skill 决定研究问题、章节结构、证据和交付物；本门控只在授权范围内优化语言、句法、衔接、信息顺序和论断强度，不替作者重新设计研究、重算结果或增加观点。

论文、学位论文、开题报告、基金申请书和正式研究报告的正文共用准确、简洁、克制、连贯、自然和专业的书面语，但各自的内容功能不能互换。正式文本应像受过专业训练的研究者向同行或责任人陈述事实，不像宣传稿、新闻稿、行政材料、教材或助手回复。

正式结果报告或论文式报告还必须与分析工作记录分开。正文直接写研究对象、结局、实际采用的方法、观察结果、解释、局限和证据边界；不得把“正文主表聚焦”“当前数据能够支持”“模型均完成估计”“两份数据可以按 ID 合并”“已经完成一致性核对”“最终效应形式”“现阶段”“待数据提供者确认”“如进入正式投稿流程”或“后续分析建议”等工作状态、版面取舍和执行指令原样写入正文。若相关事实会改变分析集、偏倚、结果或结论，应改写为正式的方法、结果或局限；仅属过程记录的内容留在内部工作记录。

- **正式**：使用学科规范术语，不写口语、口号、情绪评价或对话标签。
- **简洁**：删除没有信息增量的铺垫、解释和同义重复，不为压缩而删去证据、限定条件或必要方法。
- **准确**：具体写明主体、对象、动作、条件和范围，不用抽象词制造“高级感”。
- **克制**：论断不超过研究设计、分析层级、估计值和不确定性支持的范围。
- **连贯**：用事实关系和信息顺序建立衔接，只在真实存在递进、转折、比较或因果关系时使用连接词。
- **自然**：保持成熟作者的书面节奏，不使用翻译腔、固定段式、同义词轮换或刻意制造句式变化。
- **专业**：保留领域术语、必要 hedging、合法被动语态和统计符号，不把专业概念改成文学化表达。

正文不出现结构元话语、全局免责声明、审校过程、生成过程、内部路径或“下面将……”“本节将……”等阅读指令。方法中为复现所需的实际流程、责任、停止条件和方案偏离仍属于研究内容，应直接说明。审稿回复、rebuttal、cover letter、编辑部往来和科研邮件可以保留沟通所需的元话语，但不得把沟通套话回流到正文。

## 2 事实保真与疑问处理

语言编辑前锁定并逐项保持：研究设计、研究对象、分组、变量含义、分析层级、结论方向，以及全部样本量、百分比、β 值、OR、RR、HR、置信区间、P 值、单位、日期、引文、公式和表图指向。除非用户明确授权且新值已有权威来源，不得：

- 添加原文没有的数据、研究结果、机制解释、政策含义或参考文献；
- 删除会改变读者判断的重要结果、阴性结果、限制条件或真实披露；
- 改变统计显著性、效应方向、比较对象、参照组、分析层级或原有结论边界；
- 把相关改成因果，把不显著写成有作用，或为了顺畅而改变研究含义。

发现事实冲突、数字不一致、统计量归属不明、方法与结果不对称或统计逻辑可疑时，不在润色中偷偷纠正、补值或选择一个版本。单独写明：

> 此处可能存在内容或统计逻辑问题，建议作者核实；以下仅进行语言层面的修改。

随后只编辑不依赖该疑问的语言。若疑问会使句子没有唯一可靠改法，保留该处并列出需确认的具体对象；不能用含糊措辞掩盖问题。

原文因果措辞与已确认研究设计明显不相称时，按第 5 节降为设计支持的表达，并把该项列为“论断强度校准”。研究设计、estimand 或识别条件不明时，不自行判断作者意图，先标记待确认。

## 3 句子与段落

### 3.1 句子

- 优先使用“主体—动作—对象”结构。主语可承前省略，但不能让研究动作、判断来源或责任主体不明。
- 一个句子原则上承担一个主要逻辑任务；紧密相关的估计值、区间和限定条件可以同句呈现。出现“由于……因此……同时……此外……进一步……”等多层关系时，判断是否应拆句或重排。
- 删除同义重复，如“结果显示……研究结果表明……”“明显的显著差异”。后者按真实统计证据改为“差异有统计学意义”或具体估计。
- 拆解长定语、抽象名词链和连续多个“的”。例如把“对失能老人的照护者的负担的影响”改为“失能老人照护者的照护负担”，但不得因此改变变量定义。
- 删除无必要的翻译腔，如“不仅仅是……同时也是……”“基于……的视角下”“在……背景之下”“对于……而言”。保留确有比较或范围作用的合法用法。
- 方法和结果直接陈述研究事实，不用“为便于理解”“也就是说”“换言之”替读者解释常规内容；新方法或易混概念确需界定时，给出准确、简短且有依据的说明。

### 3.2 段落

每段围绕一个主问题组织，必要时可连续完成两个紧密功能。常见有效顺序是“核心判断—证据或解释—必要边界”，但不机械要求每段固定为主题句、2 至 4 句证据和收口句。

- 一个段落同时混入结果、机制、政策、局限和未来研究时，按部件功能拆分或重排。
- 段首直接进入对象、事实、数据、文献分歧、方法动作或限制条件，不用评价式铺垫。
- 相邻段落若重复同一主语、语序、连接词和收口方式，先合并重复论证或改变证据顺序，不靠近义词替换伪装变化。
- 标准术语允许必要重复。只有指代清楚且不会造成概念漂移时才用代词或上位词。
- 防御性转折不能代替边界说明。分别写明抽样范围、外部效度、偏倚或不确定性及其影响，不用“虽有不足但仍具有重要意义”固定收口。

## 4 部件语体

先完成所在部件的内容功能，再优化措辞。报告没有相应部件时不强行套用论文结构；研究结果报告中功能相同的部分执行同一语体门控。

### 4.1 摘要与执行摘要

- 论文摘要高度凝练，直接报告目的、设计与对象、方法、关键结果和证据相称的结论。可用“目的 分析……”或目标期刊规定的标签，不写“旨在进一步深入探讨”。
- 结果优先写“呈正向关联”“呈负向关联”“差异有统计学意义”“未达到统计学显著性”，并保留必要估计值和区间。
- 结论不得超出正文结果。报告执行摘要还应回答读者需要作出的决定、关键风险和下一步，但不得加入正文没有的判断。

### 4.2 引言与报告背景

论文引言通常从具体背景和既有证据收束到可回答的研究缺口与目的。缺口写明未知的人群、变量、时间窗、机制、方法或决策问题，例如“既往研究多考察单项因素，对家庭资源、政策认知和服务接触等分类变量的联合结构关注较少”，不用“相关研究仍然匮乏，亟待深入研究”代替。

报告背景只保留理解任务和结论所需的事实，不为“报告感”堆政策文件、宏观口号或通用意义。

### 4.3 方法

方法采用直接、客观、可复现的表达，如“采用……”“纳入……”“分为……”“定义为……”“以……为因变量”。直接说明主要、次要、敏感性或探索性分析层级，不用“为了更好地”“为更加全面地探讨”包装动作。

同行熟知的方法不写成教材；非显然且影响复现、偏倚或解释的选择理由必须保留。能直接写“将家庭状况、经济充足性、照护者积极性等 12 个分类变量纳入 MCA”时，不写“为明确进入 MCA 分析的变量，本研究将……”。

### 4.4 结果

结果只报告发现，不写机制、意义或建议。使用“比较对象/变量关系—估计值—不确定性—模型层级”的顺序，例如：

> X 与 Y 呈负向关联（β=-5.11，95%CI：-8.18～-2.03，P=0.001）。

> Z 与 Y 的关联未达到统计学显著性（β=……，95%CI：……，P=……）。

只有实际经过 FDR 校正时才写“经 FDR 校正后，……仍达到统计学显著性”。Bootstrap 或其它重抽样只归属其实际产生的区间、标准误、偏倚校正量或验证结果；若 β 和常规 95%CI 来自原模型，只把 Bootstrap 95%CI 标为重抽样结果，不写“1000 次 Bootstrap 分析显示 β=……”。

结果中避免“说明”“表明其具有重要意义”“可能是由于”“提示应加强”。表图承担完整结构化结果，正文选择关键发现，不逐格复述。

结果中的阴性或不确定发现使用中性科研语言，如“未见明确关联”“未观察到统计学显著关联”“效应估计接近无效值”或“由于可用记录较少，该结果需谨慎解释”。除非研究设计、估计对象和分析精度足以支持，不写“没有影响”“无意义”“结果不好”“不稳定所以不展示”或“没有预测价值”。术前、术后或其它时间点若均属于正式研究问题，应按实际结果分别报告；不能因为一个时间点未达显著而用“作为探索性结果不展开”隐藏它。

正文指代必须让读者立即识别范围。避免单独使用“其余指标”“主要指标”“上述变量”“两项结果”等上位词；改为明确的时间点、指标名称或完整指标集合，例如“其余术前指标”或“术后表中列出的指标”。

### 4.5 讨论、解释与建议

讨论区分本研究发现、既有证据、合理解释和推测。使用“本研究发现……”“该结果与……基本一致”“可能与……有关”“一种可能的解释是……”“既往研究提示……”。推测不能写成事实，未核验文献不能用于补机制。

横断面或其它非因果设计可写“政策认知维度与照护负担呈负向关联”。进一步解释可写“较高的政策认知可能有助于家庭获取和利用相关支持资源，但本研究无法据此判断二者的因果方向”，前提是该解释有来源或明确标为假设。

实践启示和报告建议必须与证据强度一致，并写清依据、条件、对象和责任主体。观察性或探索性证据通常使用“可考虑”“可从……方面予以关注”“提示实践中可加强……”“可为……提供参考”，不用“必须实施”“全面推广”“可有效降低”把未经验证的措施写成已证实干预。

### 4.6 局限与结论

局限直接说明问题及其对因果解释、偏倚、精度或可推广性的影响，例如“本研究采用横断面设计，无法推断因果关系”“研究对象来自单一地区，结果外推需谨慎”“部分亚组样本量较小，相关效应估计的稳定性有限”“模型未进一步调整部分潜在混杂因素，可能存在残余混杂”。不以“虽然存在不足，但仍具有重要意义”自我辩护。

结论只回答研究问题，保留适用范围和必要边界，不引入新结果、新引文或无证据政策判断。

## 5 论断与统计表达

论断强度由真实设计、estimand、识别假设、分析层级和不确定性共同决定：

| 证据情形 | 优先表达 | 避免 |
|---|---|---|
| 描述性或横断面研究 | 相关、关联、呈正向/负向关联、观察到、提示 | 导致、造成、决定、降低了、提高了、改善了 |
| 观察性纵向研究 | 与后续结局相关、发生风险较高/较低 | 证明因果、必然导致 |
| 具有明确因果 estimand 和充分识别条件的研究 | 准确写明对比、总体、结局、时间窗、效应和不确定性 | 脱离研究条件的普遍因果判断 |
| 随机试验 | 在研究条件和终点范围内降低或提高 | 永久改善、普遍有效 |
| 探索性或未校正分析 | 提示、方向一致、需验证 | 确立、证实、已证实获益 |
| 机制推测 | 可能与……有关、一种可能解释是 | 机制已明确、由……造成 |

“显著”只用于有明确统计检验的语境。“差异不显著”不等于“无差异”或“无作用”；优先报告效应方向、区间和精度。`prove`、`confirm`、“充分说明”“有力证明”等强断言只有在其具体命题、设计和证据确实支持时才保留。

## 6 术语与参考文本

同一专业概念、研究对象、变量、统计维度、量表和模型使用一个经过确认的正式名称。区分专业概念的一般用法与本文特定变量名称，不因两者词面相近而混用。

当术语变更已获全文授权时，同步检查题名、中英文摘要、引言、方法、结果、讨论、结论、表格、图题和图内标签。局部修改无权改动全文时，只修改授权位置，并把范围外发现的不一致单列给作者确认；不得以“统一术语”为由越过授权范围。

用户提供成熟论文或报告作为风格参考时，可以学习句长、信息密度、方法描述、结果报告格式、讨论展开方式、段落节奏和措辞强度。不得复制独特原句、论证内容、表头、研究事实或引文，也不得把参考文本的因果强度和统计报告方式移植到不相容设计。目标是达到相近的学术成熟度，不是模仿具体句子。

## 7 高风险表达线索

以下词语只用于定位，不能机械清零。若表达没有新增可核查信息，删除、具体化或降级；若它属于引文标题、规范术语、真实统计结果、经验证干预效果或必要逻辑关系，保留并核对依据。

| 类型 | 高风险线索 | 优先处理 |
|---|---|---|
| 公式化背景 | 近年来、随着……快速发展、受到广泛关注 | 直接写与研究问题有关的负担、政策事实、机制或证据 |
| 空转提示 | 值得注意的是、需要指出的是、众所周知、毋庸置疑、不可忽视的是、显而易见、由此可见、综上不难发现 | 直接陈述后文事实 |
| 空泛价值 | 至关重要、不可或缺、具有深远意义、具有十分重要的意义、具有重要的理论价值和现实意义、提供了有力支撑、提供了坚实基础、前景广阔 | 写明对哪个结局、判断、资源或理论的具体贡献；无信息则删 |
| 宣传性创新 | 填补空白、突破性、首次、领先 | 只陈述与既往工作的可核实差异，不替读者评价 |
| 无证据强化 | 进一步丰富、进一步拓展、进一步深化、充分说明、有力证明、有力证实、显著改善、有效促进、全面提升、大幅提高、切实提高、更稳健、更优 | 核对比较对象、估计值、设计和证据位置，必要时改为中性事实 |
| 宣传或行政口号 | 凸显、彰显、赋能、助力、多维协同、精准施策、系统性推进、形成合力、共同作用下形成、真正实现 | 改为具体主体、动作、条件和可核查结果 |
| 模糊归因 | 已有研究、部分学者、专家认为 | 指向具体真实引文；来源不明时标记待核，不补造文献 |
| 说明书式元话语 | 为了明确、为便于理解、上述变量均、这里需要说明的是、本研究之所以采用……是因为、从统计学角度来看、也就是说、换言之 | 直接写研究动作或必要理由；无信息则删 |
| 抽象名词链 | 实现……的提升、促进……的发展、开展……的构建 | 改为具体动词和对象 |
| 助手或机械衔接 | 我们可以看到、不难发现、综上所述；此外、同时、另外、与此同时、进一步连续出现 | 直接写事实；再核对句间真实逻辑，合并或重排 |

例如，“研究结果进一步充分说明了社会支持对于降低照护者负担具有十分重要的作用”在观察性研究中可改为“社会支持水平与照护者负担呈负向关联”，前提是该方向与已确认结果一致。

## 8 终审清单

提交修改结果前逐项确认：

1. 是否改变研究事实、数字、引文、变量含义、统计结论或原有证据边界？
2. 是否擅自加强或削弱结论，或把相关改成因果、把不显著写成有作用？
3. 是否加入原文和已确认来源没有的数据、机制、政策含义、观点或参考文献？
4. 是否仍有空泛提示、宣传口号、行政表达或其它模板化套话？
5. 是否存在说明书式解释、教材式展开或助手口吻？
6. 是否符合当前部件的功能和语体，结果、讨论、建议与局限是否越界？
7. 因果措辞是否与研究设计、estimand、识别条件和不确定性相称？
8. 同一术语在授权范围内是否一致，范围外不一致是否已单列而非擅自修改？
9. 是否还能在不损失证据、限定条件和专业含义的情况下压缩？
