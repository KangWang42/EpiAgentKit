# 学术与专业文本的内容、结构和表达审校

## 1 三层审校顺序

按“事实与证据 → 内容与结构 → 句子与用词”的顺序处理。只修词句而不检查论证结构，往往会得到流畅但空泛的文本。

1. 确认并保持数字、引文、公式、表图指向、研究对象、时间范围、终点和论断方向不变。
2. 检查每节、每段承担的科学或专业功能，删除重复、空转和无来源的内容。
3. 最后处理句法、连接、措辞和语气。

用户只授权最小润色时，不擅自重排结构；把影响发表或使用的结构问题单列说明。用户允许重写时，先修结构再修句子。

## 2 内容与结构审校

先逐项列出文章内容之间的关系：

`部件/段落 | 要回答的问题 | 证据来源 | 本段功能 | 读者应带走的信息`

- 论文的主轴由研究目的或 estimand、方法、结果和讨论逐项对应形成。任何主要目的都应有方法和结果承接；讨论不得引入未报告的主要发现。
- 报告的主轴由读者、决策或任务、事实依据、影响和行动形成。结论前置是文档层面的安排，不要求每一段都套“判断在先、解释在后”。
- 章节数、段落数、小标题数和列表项数由目标期刊或机构、研究设计、证据关系和读者任务决定。不得固定为四段引言、五节讨论、七段讨论或三条建议。
- 结果按研究目的、estimand、时间顺序或表图关系组织。编号列表只用于真正并列且列表比连续行文更清楚的内容，不作为“像论文”的默认格式。
- 讨论可组合主要发现、文献对照、解释、意义、优势、局限和适用边界，但不要求每个结果单独成节，也不要求每段重复同一套动作。
- 方法应保留复现、报告规范和理解选择所必需的信息。删去分析日记和软件工程流水账，但不得隐藏缺失数据处理、质量控制、方案偏离、关键诊断、选择依据或会影响偏倚判断的信息。

执行两个测试：

- **可迁移性测试**：一句或一段若几乎不改就能放进另一篇无关论文或报告，通常过于空泛。用项目中已有的对象、范围、数据、方法或真实文献具体化；没有来源时删除或标记缺口。
- **完整性测试**：删除段落标题，只读段落首尾和证据来源。如果看不出它回答什么问题、凭什么成立或如何推进全文，合并、重排或删除。

## 3 段落功能与信息密度

- 一段可以承担一个主功能，也可以在关系紧密时完成两个连续功能。不要机械要求每段都有主题句、文献、机制和意义四件套。
- 段首放在最能建立语境的位置，可以是研究对象、数据、文献分歧、方法动作或限制条件，不必轮流变换以制造“自然感”。
- 相邻段落若重复同一语序、连接词和收口方式，先检查是否结构重复；优先合并或改变论证顺序，不靠同义词替换伪装。
- 相关数字可以成组报告，再给一次解释。不得给每个数字机械附加一句“这意味着”，也不得把整张表逐格改写成散文。
- 标准术语允许重复。只有指代明确且不会造成概念漂移时才使用代词或上位词。
- 章节或段落若只有评价、愿景、背景常识或套话而没有可定位事实，应删除；篇幅不足只能补真实且必要的内容。

## 4 高风险表达模式

| 模式 | 识别信号 | 处理方式 |
|---|---|---|
| 公式化开头 | “近年来受到广泛关注”、`In recent years`、`Despite recent advances` | 直接写具体问题、证据或缺口 |
| 空泛重要性 | “至关重要”“具有深远意义”、`pivotal`、`paramount` | 写明对结局、决策、资源或理论的具体影响 |
| 宣传性创新 | “突破性”“首次”“革命性”、`groundbreaking`、`novel` | 只陈述与既往工作的可核实差异 |
| 空泛规模 | “大量”“全面”“广泛实验”、`extensive`、`comprehensive` | 写明样本、数据集、时间、指标或范围 |
| 模糊归因 | “已有研究表明”、`studies have shown` | 指向具体文献；无文献则降低为待核陈述 |
| 无证据强化 | “充分证明”“显著优于”、`prove`、`significantly outperform` | 对照研究设计、统计量、比较对象和证据位置 |
| 连接词堆叠 | 连续句以“此外/同时”、`Moreover/Furthermore` 起头 | 删除可由语义承担的连接词，必要时合并或重排 |
| 机械列举 | 固定三点、每段同一套步骤、规则化收口 | 保留真实数量，按证据关系决定段落或列表 |
| 同义词循环 | 同一构念被多个近义词轮换指代 | 固定术语，允许必要重复 |
| 句尾空转 | “凸显了重要性”、`highlighting the need` | 删除；如确有含义，改为具体结果或影响 |
| 元话语 | “值得注意的是”“我们可以看到”、`It is worth noting` | 直接陈述事实 |
| 抽象名词链 | “实现对……的提升与促进”“开展……的构建” | 改为明确主体和动作，如“模型识别”“研究者评估” |

模式命中只提示可能存在的问题。真实引文标题、规范术语或承担必要逻辑的表达不得为追求清除全部命中而改坏。

## 5 必须保留的学术表达

- 与证据强度匹配的 hedging，例如“提示”“可能”“与……一致”。
- 行为主体不重要时的被动语态，以及规范的第一人称复数 `we`。
- 方法名、模型名、量表名、公式、变量符号、引文键、表图编号、单位和必要的术语重复。
- 研究设计要求的限定条件，例如“在本队列中”“调整协变量后”“探索性分析”。
- 为理解选择与偏倚所必需的方法理由、缺失数据处理、质量控制、方案偏离和适用边界。
- 结果节必要的表图定位和讨论节必要的文献比较。

## 6 论断强度

| 证据情形 | 可用表达 | 不应使用 |
|---|---|---|
| 描述性或横断面关联 | 相关、相伴、观察到、提示 | 导致、改善、保护、危害 |
| 观察性纵向结果 | 发生风险较高、与后续结局相关 | 证明因果、必然导致 |
| 随机试验 | 在研究条件和终点范围内降低或提高 | 普遍有效、永久改善 |
| 探索性或未校正分析 | 提示、方向一致、需验证 | 确立、证实、亚组获益 |
| 机制推测 | 可能与……有关、一种解释是 | 机制已明确、由……造成 |
| 基金申请预期 | 将检验、拟评估、预期产生 | 已证明、必将实现 |

## 7 章节功能控制

先判断内容是否完成所在章节的任务，再处理措辞；不靠散落的免责声明补救章节越界。

| 章节 | 主要任务 | 不应出现 |
|---|---|---|
| 方法 | 说明做了什么、为何采用必要选择及如何复现 | 调试过程、结果评价、未披露的事后合理化 |
| 结果 | 按目的、estimand 和表图客观报告数据与模型 | 机制猜测、政策建议、把探索结果升格 |
| 讨论 | 解释主要发现、对照真实文献并说明意义与边界 | 逐项复述系数、无证据机制、防御性统计说明 |
| 局限 | 集中说明真正影响偏倚、解释或适用性的限制 | 与研究无关的泛化套话、分析日志 |
| 结论 | 回答研究问题并保持证据允许的强度 | 新结果、新引文、未经结果支持的建议 |

题名准确呈现对象、核心变量与设计；摘要关键数值与正文表格一致；引言只保留通向研究问题的背景和证据。报告则围绕读者的决策需要组织，不把同一内容重复成摘要、要点和结论三遍。

## 8 终稿验证

- [ ] 改前与改后数字、单位、统计方向、精度和时间范围一致。
- [ ] 引文标识、公式、表图编号和交叉引用未被误改，未新增虚构来源。
- [ ] 每个主要论断均可定位到数据、表图、方案或真实引文。
- [ ] 章节与段落顺序由内容关系决定，无固定段数、固定三点或重复段落模板。
- [ ] 可迁移性测试未发现可原样移植到无关研究的空泛段落。
- [ ] 相邻段落的主语、语序、连接和收口没有机械重复；必要的术语重复已保留。
- [ ] 术语、研究对象命名和必要限定语准确一致，全文符合学科通行写法与目标期刊语体，未照搬原稿中的不规范表达。
- [ ] 无口语、宣传腔、助手口吻、程序实现痕迹或为了规避检测而刻意制造的句式变化。
