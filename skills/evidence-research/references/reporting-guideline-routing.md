# 科研报告规范选择

当任务需要确定论文、研究报告或专项分析适用的报告规范时使用本参考。每次正式写作仍核验官方网站、当前版本和目标期刊要求；本文件只维护选择逻辑，不复制完整清单。

## 1. 组合原则

按实际研究依次选择：

1. 研究设计的基础报告规范；
2. 已实施统计方法的专项规范；
3. 数据采集或来源的专项规范；
4. 目标期刊当前作者指南和文章类型要求。

基础规范与专项规范叠加而不是互相替代。重叠条目只执行一次并保留更具体的要求；冲突时先核对研究设计事实和方法定义，再核对规范适用范围，不能由期刊版式改变科学口径。

## 2. 常见选择边界

| 研究或方法 | 候选规范 | 使用边界 |
| --- | --- | --- |
| 观察性队列、病例对照、横断面 | STROBE 对应设计清单及 Explanation and Elaboration | 用于完整透明报告，不是研究质量评分、设计处方或固定章节模板 |
| 基本统计方法与结果 | SAMPL | 补充样本量/分母、估计量、不确定性、P 值和方法透明度，不替代设计规范 |
| 中介分析 | AGReMA | 只在实际中介分析适用；仍需按研究设计和识别假设区分描述性分解与因果中介 |
| 研究者实施的问卷调查 | CROSS | 用于问卷调查的设计、实施和报告；数据库中含问卷变量不自动触发 |
| 随机试验 | CONSORT 及适用扩展 | 不用 STROBE 替代随机、分配隐藏、盲法、分析集和不良事件报告 |
| 预测模型 | TRIPOD 或当前适用扩展 | 关联模型不因使用回归而自动成为预测研究 |
| 诊断准确性 | STARD | 明确索引试验、参照标准、阈值、受试者流程和准确性估计 |
| 系统综述或 Meta 分析 | PRISMA 及实际方法扩展 | 报告检索、筛选、偏倚、合成和证据确定性，不套观察性原始研究结构 |

表中名称只用于发现候选来源。正式任务必须打开官方或权威来源核对当前版本、文章类型、扩展和适用范围；无法核验时标记未核验，不把名称记忆包装为当前要求。

## 3. 定位表

完整稿或论文级结构性重写把适用规范转为定位表：

```text
规范与条目 | 来源身份/版本 | 适用性及理由 | 稿件或补充材料位置 |
事实或结果来源 | 当前状态 | 阻断项 | 验收证据
```

规范原有编号与维护者措辞必须保持准确。为了执行而拆分成多个检查点时，明确这些是本地实施检查点，不冒充官方新增条目。不适用项记录判断依据，不在稿件生成空段落。

## 4. 适用性判断

- 先看研究实际做了什么，不看标题或变量名称。例如“中介”变量存在不等于实施了中介分析，“调查数据库”不等于研究者实施了问卷调查。
- 同时核对人群、时间结构、抽样、测量、estimand、模型、识别假设和输出。方法只有名称相似而目标不同，不能沿用同一组报告要求。
- 期刊要求提交清单时，清单定位必须与当前稿件真实位置一致；不能先勾选再补套话。
- 报告规范不能修复未实施的设计或分析。缺失的关键步骤应如实标为未实施、偏离或局限，并交回研究设计或分析流程判断影响。

## 5. 核验证据

优先使用规范维护组织、EQUATOR Network 收录页、原始声明论文和目标期刊官方说明。记录检索日期、来源身份、版本/发布日期、适用研究类型、正文或附件状态及更正信息。二手博客、搜索摘要和单篇使用该规范的论文只能帮助发现来源，不能定义规范内容。
