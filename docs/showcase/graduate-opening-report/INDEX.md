# 研究生学位论文开题报告结构测试

本目录保存 `graduate-opening-report` 的两份可编辑 DOCX 结构完整性测试模板。它们不编造研究背景、研究结果或出版物：每个正文模块先用一句话说明该节应完成的功能，随后用显式 `【结构测试填充：……】` 和连续 `x` 模拟长报告篇幅；需要外部来源的位置统一写成 `【引文待核验：……】`。

- [观察性队列结构测试模板（DOCX）](observational-cohort.docx)：覆盖时间零点、随访、失访、混杂控制、敏感性分析和非因果解释。
- [随机对照结构测试模板（DOCX）](randomized-intervention.docx)：覆盖随机序列、分配隐藏、实施忠实度、意向性/符合方案分析、方案偏离和安全性。

两份文件均包含 27 组完整报告模块、23 个按章节功能分配不同长度的受控填充块、8 个待核验引文条目和 12 张可编辑表格。观察性模板提取 164,864 个字符，其中 156,500 个 `x`；随机对照模板提取 165,897 个字符，其中 157,500 个 `x`。测试填充按真实中文正文预算放大，用于补偿拉丁字母比中文更紧凑的分页差异；两份文件经 Pandoc/XeLaTeX 均渲染为 23 页 A4，并抽查首、中、末页及表格页未见越界。

两份模板在 `validate_proposal.py --mode showcase` 下通过，在 `--mode archive` 下会因待补字段、待核验引文和测试填充被明确阻断。这一正反结果用于证明 skill 已记录各部分深度预算，并能组织完整章节、设计分支、表格、约 20–30 页篇幅和 DOCX 文件流程；它不证明正式正文质量、真实证据、学院模板适配或归档资格。

提交前审阅材料仅保留在维护者本地的 `09_backup/workbench/`，不作为公开展示文件或仓库依赖。
